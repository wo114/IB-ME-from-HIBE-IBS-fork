# IBME 项目重建工作记录

更新日期：2026-10-04。此文件是新工作的进度入口；旧 M1 至 M3 仅描述教学原型的功能进度。最新原语准入结论以本文件和第二轮审查为准，早期报告中的精读优先级保留为历史记录。

## 1 已确认决定

1. 通用构造采用王老师的两层匿名 HIBE + 自适应安全 IBS，依据 Wang 论文 §4 的 Construction 1 与 Theorem 4.2。身份顺序始终为接收者在第一层、发送者在第二层。
2. 不实施、不宣称 Boyen–Li 增强隐私，不开发 Ext、ReExt、enhanced.py 或另一套匿名 IBE 通用协议。相关论文只用于说明性质边界。
3. 普通隐私、加强认证、自我伪造防护、四种匹配情况和赛题的密文篡改拒绝仍是目标。密文字节完整性需要单独论证，不能直接由消息签名推出。
4. HIBE、IBS 的具体算法与正式参数仍需选择。先核验论文、安全游戏、采样与参数，再比较完整组合的尺寸、时间和内存。功能测试不构成安全证明。
5. 按时间充分安排研究，通过成果验收推进；不采用旧资料里的截止日期缩减研究。
6. 用户已授权完成工作后提交并更新远端私有仓库。每轮保持一个可审查任务边界，遵守 AGENTS.md 的文件、测试、提交与安全声明规则。

## 3 下一轮的单项任务

**审查 Wang 基本 IBS + Pan–Wagner 自适应转换的固定用户密钥复用。** 下一轮不同时编写多个原语，不重做通用构造。

验收材料必须包括：

1. 固定身份、固定已发密钥及身份盐下，多次签名、重复消息、重新发钥和腐化查询的实际转录。
2. 与论文 KeyExt、OSig、缓存和转换归约的逐项对应；检查联合分布，而非只看单次正确性。
3. 明确的“可接入 / 需补充证明 / 不适合”结论；需要新证明时写出安全实验、模拟器依赖和损失，不能只加缓存就放行。
4. 完整转换字段、采样与参数依赖清单；与 Wang 所需自适应不可伪造游戏对照。

Foo–Li 只有在分支关联、范数和查询预算等问题有完整澄清或独立修订证明后才能恢复准入。没有必要为了沿用首轮优先级而强行实现。

ABB10 可在独立数学研究模型中推进完整格基与委派实验，保持 `security_claim: none`；原始一比特算法不直接注册为满足字节载荷和失败返回契约的后端。冻结公开接口保留，参数类型和载荷适配待正式实现任务前单独冻结。

## 4 当前安全状态

密码代码及参数未改变。当前参数仍为 HIBE 的 n=8、m=168、q=524288 与 IBS 的 n=8、m=80、q=257，均为教学参数，`security_claim: none`。本轮没有生成生产密钥、运行新的格安全估计或性能基准。

2026-10-03 首次核验中的公开参数伪造成功和单字节密文修改被接受仍是有效反例。333 项测试通过、10 项跳过是历史结果，不能作为新安全实例通过的证据。本轮 13 项检查只验证研究枚举和代数工具，同样不证明密码安全。

真实离散高斯、正式参数、完整性包装和环格或模格后端均未实现。增强隐私属于明确排除的范围，不列为待实现缺口。
