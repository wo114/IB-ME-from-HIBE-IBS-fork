## 1 已确认决定

1. 通用构造采用王老师的两层匿名 HIBE + 自适应安全 IBS，依据 Wang 论文 §4 的 Construction 1 与 Theorem 4.2。身份顺序始终为接收者在第一层、发送者在第二层。
2. 不实施、不宣称 Boyen–Li 增强隐私，不开发 Ext、ReExt、enhanced.py 或另一套匿名 IBE 通用协议。相关论文只用于说明性质边界。
3. 普通隐私、加强认证、自我伪造防护、四种匹配情况和赛题的密文篡改拒绝仍是目标。密文字节完整性需要单独论证，不能直接由消息签名推出。
4. HIBE、IBS 的具体算法与正式参数仍需选择。先核验论文、安全游戏、采样与参数，再比较完整组合的尺寸、时间和内存。功能测试不构成安全证明。
5. 按时间充分安排研究，通过成果验收推进；不采用旧资料里的截止日期缩减研究。
6. 用户已授权完成工作后提交并更新远端私有仓库。每轮保持一个可审查任务边界，遵守 AGENTS.md 的文件、测试、提交与安全声明规则。

## 3 下一轮的单项任务

**解除大模数／高维采样的全中心预计算瓶颈。** 单项验收是任意有理中心的在线一维高斯、一般 gadget 与非球形扰动的统一有限误差及按调用资源契约，再提供数学参考实现和与既有组件的独立对照。第九轮已完成二进制单列的真实生成／委派／用户采样及整类准入，下一步不继续靠扩大该样例代替可扩展性。Sage 一律使用 WSL 的 `~/miniconda3/envs/sage`。

验收材料必须包括：

1. 任意中心归约和统一宽度／尾界，不先枚举数量可能巨大的全部中心；公开资源拒绝及固定带语义保持可审查。
2. 真实一般模数 gadget 和相关整数扰动的无限目标误差，继续使用完整 MP12 协方差补偿；不改成解线性方程或无扰动采样。
3. 与第四至九轮组件做独立分布／重放对照，并展示原本超出中心预计算上限的实例；更大的模方程成功仍不作为安全证明。
4. 保留第七轮 E、α_R、α_z、ν、β_red 账本，重新核验近均匀主生成、合格用户质量失败及实用参数。第九轮的 0.4602 公开偏差、约 6.02% 质量上界和非法 SIS 范数区间不能沿用为安全参数。
5. 维持质数模数和 Foo–Li 主线，正式参数须有完整有限链和格攻击估计；规范编码、持久种子、签后腐化及攻击回归仍是后端准入条件，保持 `security_claim: none`。

这项工作完成后才推进更大参数的实际生成／委派连通及正式有限参数选择。不默认转向 Wang + PW，也不因教学小参数的失败淘汰 Foo–Li。

第三轮的条件归约逻辑及完整联合采样界仍须独立审查。数学参考基础可以先推进；正式 IBS 后端须在缓存发钥生命周期、基础批量实验、统一分布和参数损失闭合后才准入。同一身份多份独立密钥的模型当前未覆盖。

两项修复已经明确分工与终点：旧公开伪造由合法参数及真实 Foo–Li 后端替换解决，并保留公开稀疏求解和 LLL 回归；外层篡改由完整密文认证包装单独论证和版本化实现解决，须覆盖持钥接收者自我伪造。安全 IBS 不会自动拒绝所有外层格系数修改，公开 checksum 或接收者已知密钥的 MAC 不能作为最终修复。理论主线与各项修复均不免除最终攻击回归。

一维、二进制及小模数一般 gadget 已接入完整 MP12 SampleD 数学参考链，包括非球形扰动。真实高斯生成和独立列委派已经实现，本轮对二进制单列全部合格陷门提供统一资源与有限误差界；一般质数／多列仅提供生成和委派算法及代数检查。大模数高效采样、高维统一准入、可忽略近均匀及质量预算、正式参数、完整性包装及环格或模格后端仍未完成。参考组件使用可变时间采样，允许显式中止，误差界假设独立均匀随机字节；不是生产安全实现。增强隐私属于明确排除的范围，不列为待实现缺口。
