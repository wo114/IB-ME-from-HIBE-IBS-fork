# IBME 项目重建工作记录

更新日期：2026-10-04（第三轮）。此文件是新工作的进度入口；旧 M1 至 M3 仅描述教学原型的功能进度。最新 IBS 准入结论以本文件和第三轮审查为准，早期报告中的优先级保留为历史记录。

## 1 已确认决定

1. 通用构造采用王老师的两层匿名 HIBE + 自适应安全 IBS，依据 Wang 论文 §4 的 Construction 1 与 Theorem 4.2。身份顺序始终为接收者在第一层、发送者在第二层。
2. 不实施、不宣称 Boyen–Li 增强隐私，不开发 Ext、ReExt、enhanced.py 或另一套匿名 IBE 通用协议。相关论文只用于说明性质边界。
3. 普通隐私、加强认证、自我伪造防护、四种匹配情况和赛题的密文篡改拒绝仍是目标。密文字节完整性需要单独论证，不能直接由消息签名推出。
4. HIBE、IBS 的具体算法与正式参数仍需选择。先核验论文、安全游戏、采样与参数，再比较完整组合的尺寸、时间和内存。功能测试不构成安全证明。
5. 按时间充分安排研究，通过成果验收推进；不采用旧资料里的截止日期缩减研究。
6. 用户已授权完成工作后提交并更新远端私有仓库。每轮保持一个可审查任务边界，遵守 AGENTS.md 的文件、测试、提交与安全声明规则。

本轮核对 Wang 基本 IBS 与 Pan–Wagner ROM 转换。PW Figure 1 每次签名重新发钥，实际保存的密钥会复用身份盐；照搬其 G1 在第二次同身份签名时会必然中止。本轮明确缓存安全实验，并提出 B0/B1 两分支条件归约：猜测一个目标槽位，其余槽位预取密钥，从而允许其他用户先签名、后腐化。候选损失约 K+1，K=max(1,Q_C+Q_S)，不再沿用原文紧归约。

该补充依赖 SamplePre 对所有合格固定陷门的条件化统一分布界、基础批量 UF-naCMA 映射和有限碰撞/采样预算，仍需证明审查。优先研究 Wang + PW 作为数学参考候选，不表示完成正式安全 IBS。完整审查和条件草案见 [第三轮研究记录](research/2026-10-04-round3/Wang与PanWagner固定密钥接入审查.md)。
