# IBME 项目重建工作记录

更新日期：2026-10-04（第四轮）。此文件是新工作的进度入口；旧 M1 至 M3 仅描述教学原型的功能进度。IBS 准入结论以本文件和第三轮审查为准；采样参考组件进度以第四轮报告为准。早期报告中的优先级保留为历史记录。

## 1 已确认决定

1. 通用构造采用王老师的两层匿名 HIBE + 自适应安全 IBS，依据 Wang 论文 §4 的 Construction 1 与 Theorem 4.2。身份顺序始终为接收者在第一层、发送者在第二层。
2. 不实施、不宣称 Boyen–Li 增强隐私，不开发 Ext、ReExt、enhanced.py 或另一套匿名 IBE 通用协议。相关论文只用于说明性质边界。
3. 普通隐私、加强认证、自我伪造防护、四种匹配情况和赛题的密文篡改拒绝仍是目标。密文字节完整性需要单独论证，不能直接由消息签名推出。
4. HIBE、IBS 的具体算法与正式参数仍需选择。先核验论文、安全游戏、采样与参数，再比较完整组合的尺寸、时间和内存。功能测试不构成安全证明。
5. 按时间充分安排研究，通过成果验收推进；不采用旧资料里的截止日期缩减研究。
6. 用户已授权完成工作后提交并更新远端私有仓库。每轮保持一个可审查任务边界，遵守 AGENTS.md 的文件、测试、提交与安全声明规则。

第三轮核对 Wang 基本 IBS 与 Pan–Wagner ROM 转换。PW Figure 1 每次签名重新发钥，实际保存的密钥会复用身份盐；照搬其 G1 在第二次同身份签名时会必然中止。该轮明确缓存安全实验，并提出 B0/B1 两分支条件归约：猜测一个目标槽位，其余槽位预取密钥，从而允许其他用户先签名、后腐化。候选损失约 K+1，K=max(1,Q_C+Q_S)，不再沿用原文紧归约。

该补充依赖 SamplePre 对所有合格固定陷门的条件化统一分布界、基础批量 UF-naCMA 映射和有限碰撞/采样预算，仍需证明审查。优先研究 Wang + PW 作为数学参考候选，不表示完成正式安全 IBS。完整审查和条件草案见 [第三轮研究记录](research/2026-10-04-round3/Wang与PanWagner固定密钥接入审查.md)。

第四轮已实现一维整数/等差陪集离散高斯参考采样，使用 MPFI 区间 π/exp、精确有理端点、整数概率表、几何尾界和无偏随机整数。论文参数 `s` 与旧接口 `sigma` 的关系明确为 `s=sqrt(2*pi)*sigma`，没有改冻结的生产接口。

`q=2^k` gadget 已实现 MP12 奇偶递推；除了验证模方程，还用无限奇偶高斯归一化质量的区间控制偏差。窄参数有限盒对照显示方程正确时分布仍可相差约 23.2%；较宽研究样例 `q=16,n=2,s=12` 的无限目标总变差上界约 `4.0575e-24`，8192 个输出的模方程均正确。两类距离的目标不同，不作为安全等级或性能比较。

指定 WSL Sage 环境中 75 项研究工具测试通过（本轮 42 项、第三轮 20 项、第二轮 13 项）。原生 Windows 同一选择为 33 项通过、1 个 Sage 模块跳过。详细依据、失败修正和参数见 [第四轮参考实现报告](research/2026-10-04-round4/离散高斯与gadget陪集采样参考实现.md)。没有实现正式密码后端，没有选定正式参数。

## 3 下一轮的单项任务

**建立 MP12 §4.2 的一般模数 gadget 陪集参考采样，优先覆盖质数 q。** 在 WSL 的 `~/miniconda3/envs/sage` 内进行，沿用本轮有限误差方法。

原因是 Wang Lemma 2.1（PDF 7）限定 q prime，而本轮 gadget 使用 `q=2^k`，k>1 时不满足该条件。MP12 的一般 q 方案可以先解决组件兼容性；若最终选择 2 的幂模数，则必须独立替换并审查 Wang 对应的质数引理。目前未选择新的正式证明路线。

验收材料必须包括：

1. 构造一般 q 的完整整数 gadget 格基，核验行列式、模方程与 Gram–Schmidt 的采样顺序。
2. 明确非整数高斯宽度的平方参数及精确有理中心编码；对条件化中心的变化给出统一有限误差预算。
3. 对质数、合数与 2 的幂模数做数学交叉核验，分别检验有限盒目标和无限目标误差；不能只检查直方图或把一般 q 按 `2^k` 递推。
4. 新随机性与测试固定随机性分开，记录拒绝、中止、样本数、环境与复现命令。保持 `security_claim: none`。
5. 明确与 TrapGen、DelTrap、MP12 §5.4 扰动协方差和完整 SamplePre 的未完成连接；协方差正定本身不够，还须审查卷积、平滑宽度和坏陷门事件。

第三轮的条件归约逻辑及完整联合采样界仍须独立审查。数学参考基础可以先推进；正式 IBS 后端须在缓存发钥生命周期、基础批量实验、统一分布和参数损失闭合后才准入。同一身份多份独立密钥的模型当前未覆盖。

Foo–Li 只有在分支关联、范数和查询预算等问题有完整澄清或独立修订证明后才能恢复准入。没有必要为了沿用首轮优先级而强行实现。

ABB10 可在独立数学研究模型中推进完整格基与委派实验，保持 `security_claim: none`；原始一比特算法不直接注册为满足字节载荷和失败返回契约的后端。冻结公开接口保留，参数类型和载荷适配待正式实现任务前单独冻结。
