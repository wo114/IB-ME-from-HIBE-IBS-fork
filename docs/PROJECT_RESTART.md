## 1 已确认决定

1. 通用构造采用王老师的两层匿名 HIBE + 自适应安全 IBS，依据 Wang 论文 §4 的 Construction 1 与 Theorem 4.2。身份顺序始终为接收者在第一层、发送者在第二层。
2. 不实施、不宣称 Boyen–Li 增强隐私，不开发 Ext、ReExt、enhanced.py 或另一套匿名 IBE 通用协议。相关论文只用于说明性质边界。
3. 普通隐私、加强认证、自我伪造防护、四种匹配情况和赛题的密文篡改拒绝仍是目标。密文字节完整性需要单独论证，不能直接由消息签名推出。
4. HIBE、IBS 的具体算法与正式参数仍需选择。先核验论文、安全游戏、采样与参数，再比较完整组合的尺寸、时间和内存。功能测试不构成安全证明。
5. 按时间充分安排研究，通过成果验收推进；不采用旧资料里的截止日期缩减研究。
6. 用户已授权完成工作后提交并更新远端私有仓库。每轮保持一个可审查任务边界，遵守 AGENTS.md 的文件、测试、提交与安全声明规则。
7. 2026-10-06 用户确认多实例以不同格困难假设为主轴。同一矩阵 SIS 下的 Foo–Li 与 Wang + PW 属于算法对照，不计为两个困难假设实例；更换采样器或参数也不增加假设类别。扩展按矩阵、环、模路线组织，混合组合分别标注 HIBE/IBS 的真实依赖。具体路线与验收见 [专项说明](research/2026-10-06/多困难假设实例化口径与验收.md)。此前“第二套 IBS 或 HIBE”的任务表述由本项细化，不能仅靠同族算法替换完成 G4。

## 4 当前安全状态

生产密码代码及参数未改变。当前参数仍为 HIBE 的 n=8、m=168、q=524288 与 IBS 的 n=8、m=80、q=257，均为教学参数，`security_claim: none`。本轮生成了真实数学参考主陷门、委派陷门、扰动和原像，没有生成生产密钥、运行新的格安全估计或性能基准。

2026-10-03 首次核验中的公开参数伪造成功和单字节密文修改被接受仍是有效反例。333 项测试通过、10 项跳过是历史结果，不能作为新安全实例通过的证据。研究检查验证格基、条件化采样、完整 SampleD 的有限分布、联合转录、查询流程、好矩阵/后验概率预算及代数工具；没有生成真实 IBS 签名，不证明密码安全。第十轮结果与完整命令见本轮核验记录。

两项修复已经明确分工与终点：旧公开伪造由合法参数及真实 Foo–Li 后端替换解决，并保留公开稀疏求解和 LLL 回归；外层篡改由完整密文认证包装单独论证和版本化实现解决，须覆盖持钥接收者自我伪造。安全 IBS 不会自动拒绝所有外层格系数修改，公开 checksum 或接收者已知密钥的 MAC 不能作为最终修复。理论主线与各项修复均不免除最终攻击回归。

任意有理中心、一般 gadget 及精确相关整数扰动已接入完整 MP12 在线参考链。在公共预算合格的 128 维范围内，提供全部质量合格陷门的资源与有限误差界，并完成大质数模数、多列真实生成／委派／用户采样。当前调试主生成明确可公开恢复，SIS 范数门槛通过不构成安全。生产维度的高效采样、可忽略近均匀及质量预算、正式参数、完整性包装及环格或模格后端仍未完成。参考组件使用可变时间采样，允许显式中止，误差界假设独立均匀随机字节；不是生产安全实现。增强隐私属于明确排除的范围，不列为待实现缺口。
