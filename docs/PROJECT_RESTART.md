# IBME 项目重建工作记录

更新日期：2026-10-04（第六轮）。此文件是新工作的进度入口；旧 M1 至 M3 仅描述教学原型的功能进度。IBS 候选和准入结论以本文件、第三及第六轮审查为准；采样参考组件进度以第四、五轮报告为准。早期报告中的优先级保留为历史记录。

## 1 已确认决定

1. 通用构造采用王老师的两层匿名 HIBE + 自适应安全 IBS，依据 Wang 论文 §4 的 Construction 1 与 Theorem 4.2。身份顺序始终为接收者在第一层、发送者在第二层。
2. 不实施、不宣称 Boyen–Li 增强隐私，不开发 Ext、ReExt、enhanced.py 或另一套匿名 IBE 通用协议。相关论文只用于说明性质边界。
3. 普通隐私、加强认证、自我伪造防护、四种匹配情况和赛题的密文篡改拒绝仍是目标。密文字节完整性需要单独论证，不能直接由消息签名推出。
4. HIBE、IBS 的具体算法与正式参数仍需选择。先核验论文、安全游戏、采样与参数，再比较完整组合的尺寸、时间和内存。功能测试不构成安全证明。
5. 按时间充分安排研究，通过成果验收推进；不采用旧资料里的截止日期缩减研究。
6. 用户已授权完成工作后提交并更新远端私有仓库。每轮保持一个可审查任务边界，遵守 AGENTS.md 的文件、测试、提交与安全声明规则。

第六轮按用户授权恢复 Foo–Li 的独立证明研究候选资格，保留上述原证明审查。新实验将用户种子作为持久私钥状态，并允许其他身份先签名、后公开完整密钥/种子。两个候选模拟器始终返回同一个身份分支：B_same 在目标合法分支编程零 tag 原像；B_other 用已知合法陷门签名、在另一个零 tag 分支保留隐藏原像。其他用户始终保留真实确定性 SampleD 和随机带，避免腐化后重算不一致。

身份首次出现于任意公开域、Key、Sig 或最终验证时即注册槽位；保守 K=max(1,Q_C+Q_S+Q_pub+1)，两个 SIS 归约的候选主项损失为 2K。补充了质数模数下好矩阵的有限质量界与条件原像最大点概率；不再从 image 均匀推断后验仍是无条件 Gaussian，也不以非零向量差代替非零 SIS 解证明。

本轮新增 61 项检查，指定 WSL Sage 环境中六个研究模块合计 189 项通过；Windows 同一选择为 77 项通过、3 个 Sage 模块跳过。无真实矩阵/高斯/密钥/签名实验，无正式参数或新的格安全估计。符号核验和好矩阵算术不能替代完整安全归约。详见 [第六轮条件草案](research/2026-10-04-round6/FooLi固定密钥经典ROM条件归约草案.md)。

第三轮核对 Wang 基本 IBS 与 Pan–Wagner ROM 转换。PW Figure 1 每次签名重新发钥，实际保存的密钥会复用身份盐；照搬其 G1 在第二次同身份签名时会必然中止。该轮明确缓存安全实验，并提出 B0/B1 两分支条件归约：猜测一个目标槽位，其余槽位预取密钥，从而允许其他用户先签名、后腐化。候选损失约 K+1，K=max(1,Q_C+Q_S)，不再沿用原文紧归约。

该补充依赖 SamplePre 对所有合格固定陷门的条件化统一分布界、基础批量 UF-naCMA 映射和有限碰撞/采样预算，仍需证明审查。优先研究 Wang + PW 作为数学参考候选，不表示完成正式安全 IBS。完整审查和条件草案见 [第三轮研究记录](research/2026-10-04-round3/Wang与PanWagner固定密钥接入审查.md)。

第四轮已实现一维整数/等差陪集离散高斯参考采样，使用 MPFI 区间 π/exp、精确有理端点、整数概率表、几何尾界和无偏随机整数。论文参数 `s` 与旧接口 `sigma` 的关系明确为 `s=sqrt(2*pi)*sigma`，没有改冻结的生产接口。

`q=2^k` gadget 已实现 MP12 奇偶递推；除了验证模方程，还用无限奇偶高斯归一化质量的区间控制偏差。窄参数有限盒对照显示方程正确时分布仍可相差约 23.2%；较宽研究样例 `q=16,n=2,s=12` 的无限目标总变差上界约 `4.0575e-24`，8192 个输出的模方程均正确。两类距离的目标不同，不作为安全等级或性能比较。

第四轮的 75 项检查及失败修正保留在 [第四轮参考实现报告](research/2026-10-04-round4/离散高斯与gadget陪集采样参考实现.md)。

第五轮完成 MP12 一般 q 完整整数格基和随机最近平面参考采样。每一步的高斯宽度平方、Gram–Schmidt 及条件中心都用精确有理数，构造成功前预计算所有可能中心余数类。`q=17,n=2,s_squared=144` 的 469 个中心类已核验，8192 次十维输出模方程错误为零，无限球形目标的总变差上界约 `5.7796e-24`；所有参数仍为手选研究样例。

2 的幂模数逆向顺序下，与第四轮奇偶采样在同一随机流中输出逐项相同；整个第四轮保存结果复跑不变。一般模数前向预计算有资源上限，q=257 需 116761 个中心类，仅核验了格基，未作为采样参数准入。不能把小参数组件的完成等同于大模数采样或正式 IBS 准入。
