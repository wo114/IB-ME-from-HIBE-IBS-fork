# Web 演示改版

**目标：** 减少首屏信息量，突出消息加密与身份匹配，接入报告 A/B/C 三个固定配置。

**范围：** `src/ibme/webui/`、相关测试、Web 使用说明。报告、密码算法、参数及历史实验均不修改。使用现有隔离工作区的新分支，按用户要求单独实施，不调用子智能体。

## 设计

- 白色页面、深灰文字、细分隔线，无渐变、阴影卡片或彩色方案标签。主要布局为方案侧栏与消息／解密结果工作区，窄屏顺序排布。
- 默认只展示 A/B/C，Falcon 和 Luo 收入补充方案。固定配置随包发布，与已冻结 Suite 逐字段相等，不能继承 registry 的其它默认值。
- 删除安全说明、声明徽标和证明免责声明。参数与尺寸详情折叠；运行记录单独切换，保留公开测量 JSON 导出。
- 自动检查选中方案；初始化后锁定方案与身份。先加密，再选择一种测试情形解密；保留正确身份、三类错配、篡改与截断。
- 长操作由主解释器线程串行执行；HTTP 在独立线程响应静态页面与任务轮询，保留 Sage 信号初始化要求。展示真实执行阶段和已经等待的时间，不生成虚假百分比。
- 刷新后连接同一在内存中的任务／会话。服务重启清空会话；不新增密钥磁盘保存，也不把页面重连表述为服务重启恢复。
- 页面和任务错误明确显示失败，不能将后端异常算作协议拒绝。导出不包含密钥、身份文本或消息。
