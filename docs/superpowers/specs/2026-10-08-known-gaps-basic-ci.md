## 回归检查

新增 `tests/test_known_security_gaps.py`，检查三项真实安全目标：

1. 无签名密钥、只有公钥的稀疏线性求解伪造应被 IBS 验证拒绝。
2. 不调用发送者发钥，公开构造的冒名密文应被协议解密拒绝。
3. 合法密文单字节修改后应被完整性验收拒绝；先检查未修改密文正常解密，再确认修改密文仍能规范加载，避免把格式错误当作密码完整性。

首次执行不加预期失败标记，保存真实失败证据。由于旧教学实例的漏洞尚未修复，随后给安全目标断言添加 `strict=True`、`raises=AssertionError` 的 XFAIL，并在每项断言标记处注明具体原因。构造、解析、正常解密等前置条件放在断言标记外；这些意外错误必须导致普通失败，不被 XFAIL 吞掉。

修复后断言意外通过会令 CI 报错，要求维护者核验并移除标记。`pytest --runxfail` 用于忽略标记、按真实安全目标运行；在当前版本应失败，不能作为已经通过的安全验收。

## 基础 CI

新增 GitHub Actions 工作流，运行 Windows 下固定 Python 的编码、格基础、哈希准备和已知漏洞测试。使用只读仓库权限；PR 不读取秘密；不使用 pull_request_target；输出 pytest 详情、JUnit XML 与任务摘要。

已知 XFAIL 作为明确未修复状态记录，不能合并进通过数。工作流声明本批次不验证 Sage 研究采样、Lean、全部协议或密码安全。固定 pytest 版本便于重放。
