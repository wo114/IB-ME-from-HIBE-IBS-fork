## 4. 已写出的代码

### experiments/research/chkp_basis.py

[代码](../../../experiments/research/chkp_basis.py)使用 Sage 的精确 `ZZ`、`QQ` 和 `GF`。

| 对象/函数 | 已实现的作用 | 不能误解成什么 |
|---|---|---|
| `CHKPAlgebraParams(n,m,q,depth=2)` | T1 维度和素数模数检查；不截断大整数 | 不是完整密码参数；没有各层宽度和噪声条件 |
| `ModMatrixReference` | 不可变模矩阵、维度/模数检查、横向拼接 | 不是现有 uint32 wire 的替代实现 |
| `KernelBasis(public,basis_rows)` | 检查核包含关系与完整格指数 | 不是短陷门、随机化基或正式密钥 |
| `complete_kernel_basis(public)` | 用模素数域主元公开构造完整整数核格基 | 不是论文 Proposition 3.1 的 GenBasis |
| `ext_basis(parent,block)` | 实现 Lemma 3.2 的块三角扩展 | 不是 RandBasis，不可直接交给子用户作为秘密密钥 |
| `gram_schmidt_squared_lengths` | 列基的精确有理 GS 范数平方 | 不是分布检查、Gaussian 采样或安全估计 |
| `two_level_matrices` | 按输入块生成根/父/子三组矩阵 | 不实现随机预言机；块由调用者显式提供 |

基向量是矩阵的**列**；`basis_rows` 存储该矩阵的行，仅是容器布局。整数基不先约模，保留负号和完整数值；只有公开模矩阵做模约简。

ExtBasis 采用论文中的

$$
S' = \begin{pmatrix}S&W\\0&I\end{pmatrix},\qquad AW=-\bar A\pmod q.
$$

验收完整基要求同时检查 $AS=0\pmod q$ 和 $|\det S|=q^n$。只检查方程不能排除真核格的严格子格。

当前实现明确限制模数为经 Sage 证明的素数。Lemma 3.2 的更一般群生成情形不在本轮实现范围，不能把素数域高斯消元宣称为所有合数模数的支持。

### tests/test_chkp_basis.py

[测试](../../../tests/test_chkp_basis.py)覆盖根/父/子列数 $m,2m,3m$、非前导主元、行列式、模关系、成员枚举、任意幺模父基、GS 不变、负整数、61 bit 模数、非法维度、非完整子格和输入快照。

## 6. 当前两项失败：从这里继续

最近一次完整运行：**2 failed、14 passed，4.55 秒，退出码 1**。

失败是：

1. `test_root_parent_child_dimensions_and_order`：

   ```python

   ```

   Sage 矩阵直接迭代返回行向量，`int(x)` 因而抛 `TypeError`。

2. `test_exhaustive_membership_not_just_kernel_containment`：

   ```python
   all(int(x) % 3 == 0 for x in a * v)
   ```

   同一原因，枚举在第一项检查处停止，没有完成 81 个候选的全面验收。

队友可先将矩阵逐项遍历改成 `(a_z * s_z).list()` 与 `(a * v).list()`，同时检查该测试后续 `coords` 的遍历，也应逐标量使用 `coords.list()`。
这是建议的接续修正，**交接时尚未修改或重跑**；不能承诺只改这三处就一定全绿。
