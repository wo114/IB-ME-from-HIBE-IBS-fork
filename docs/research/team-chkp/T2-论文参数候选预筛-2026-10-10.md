# CHKP 论文参数候选预筛

日期：2026-10-10。本文执行“保留小参数回归、转向论文关系、先做静态预筛”的第一轮，不宣布正式参数，不注册安全后端。

## 1. 为什么没有直接抄一组“论文参数”

CHKP 作者全文在 §5.1 Lemma 5.1、§5.2 式 (5.1)/(5.2) 和 §5.3 ROHIBE 中给出了参数关系，但没有给出一套可以直接复制到本项目的完整数值元组。明确的关系包括：

\[
m \ge Cn\log_2q,\qquad q\ge 4s_t(m_t+1),
\]

以及深度二的维度关系

\[
m_t=(t+1)m,\qquad m_0=m,\ m_1=2m,\ m_2=3m.
\]

正确性还要求选择误差率满足

\[
1/\alpha \ge s_d\sqrt{m_d+1}\,\omega(\sqrt{\log n}).
\]

论文中的常数 `C` 和 `ω` 尾部因子没有被指定为本项目可以直接使用的固定数值。因此本轮不擅自声称“原论文参数已经确定”，而是把候选值作为输入做可追溯预筛。

原文与项目规格对应如下：

| 条件 | 来源 | 本轮处理 |
|---|---|---|
| `m >= C n log2(q)` | CHKP §5.1、§5.3 | 只报告 `C` 未指定；检查保守底线 `m >= n ceil(log2 q)` |
| `q >= 4 s_t (m_t+1)` | Lemma 5.1、式 (5.2) | 用平方整数式逐层检查，不使用浮点平方根 |
| `m_t=(t+1)m` | CHKP §5.3 | 检查根、一级、二级叶维度 |
| `1/alpha` 条件 | Lemma 5.1、式 (5.1) | 暂记为未评估，等待尾部因子和误差模型冻结 |
| `GenBasis`、`RandBasis`、`SampleD` 资源 | 论文算法与项目实现 | 需要真实基和采样器运行，静态预筛不替代实测 |

## 2. 当前小参数基线

当前小参数被保留为回归基线，不再作为正式候选：

| 字段 | 当前值 | 口径 |
|---|---:|---|
| `n` | 1 | 公开教学/诊断参数 |
| `m` | 10 | 根公开维度 |
| `q` | 2 | 不满足 CHKP KEM 正确性所需的 `q >= 4s_t(m_t+1)` |
| `s1^2` | 9064 | 当前一级叶路径审计宽度 |
| `s2^2` | 15952640 | 当前二级叶路径审计宽度 |
| `epsilon_bits` | 16 | 采样误差检查输入，不是安全位数 |

预筛器将这组值作为负向基线运行。它应当因为 CHKP 的 `q`—`s_t` 正确性条件失败，而不是被错误标记为正式参数通过。

## 3. 当前实现的硬门槛

项目 GPV 研究实现的维度上限为 192。深度二叶节点维度为 `3m`，因此当前代码能够接收的根维度上限是 `m <= 64`。这只是当前研究实现的资源上限，不是 CHKP 理论上限。

此外，当前 AP09 研究实现还限制 `n <= 16`、`q <= 2^61-1`、根基总维度不超过 192；`RandBasis` 单次随机带上限为 256 MiB。真实基生成后仍需重新测量：

- 一级和二级扩展基的 GS 长度；
- `SampleD` 各坐标的宽度和随机带；
- 中间节点 `RandBasis` 的候选数、秩失败预算和 `ToBasis` 资源；
- 叶节点直接 `SampleD` 的目标数量、缓存容量和整批随机带；
- 加密误差、解密噪声与 `alpha` 条件。

## 4. 已加入的可执行预筛

脚本：`experiments/research/chkp_paper_preflight.py`

它接受 `n,m,q,s1^2,s2^2`，执行：

1. 深度二维度计算；
2. `m >= n ceil(log2 q)` 的保守底线检查；
3. `q >= 4s_t(m_t+1)` 的逐层精确平方检查；
4. 当前 GPV/AP09 维度、素数模数和实现上限检查；
5. 明确列出 `alpha`、实际 GS、随机带、噪声和 IBS 组合仍未闭合的项目。

示例命令：

```text
python -m experiments.research.chkp_paper_preflight --n 1 --m 10 --q 2 --s1-squared 9064 --s2-squared 15952640
```

该命令的退出码为 2，表示当前小参数没有通过论文关系预筛；这是预期的负向基线结果。预筛通过也只表示已知静态条件通过，脚本始终输出 `backend_admitted=false` 和 `security_claim=none`。

## 5. 下一轮执行顺序

1. 队长确定或提供一组带来源的 `n,m,q,s1,s2,alpha` 候选；
2. 先运行本预筛，拒绝明显不满足维度、模数或 `q`—宽度条件的候选；
3. 对通过者运行 `GenBasis -> 一级 RandBasis -> ExtBasis -> 叶节点 SampleD`；
4. 对仍需继续委派的中间节点单独运行 `RandBasis`；
5. 记录真实随机带、内存、失败事件和噪声，而不是用小参数结果外推；
6. 结合最终 IBS 参数、组合安全目标和性能测量后，才能冻结正式参数。

## 6. 结论边界

本轮完成的是参数来源整理和静态预筛工具。小参数证据继续保留；它不被删除，也不被改写成安全证据。论文关系预筛通过不等于完整 HIBE 正确性、安全性或正式参数已经完成。

当前统一状态仍为：`parameters_are_formal=false`、`backend_admitted=false`、`security_claim=none`。
