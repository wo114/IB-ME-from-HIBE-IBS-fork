# T2 叶节点最小路径契约：原文条件与代码闭合结果

日期：2026-10-10。本文只闭合 T2 中“最大深度叶节点不生成二级委派基”的路径条件，不宣称整个 T2、完整 HIBE 或正式参数已经完成。

## 1. 结论

CHKP/Bonsai Trees 作者版第 20 页 §5.2 的 `GENHIBE.Extract` 明确给出：对新身份先执行

```text
x_id' <- SampleD(ExtBasis(S_id, A_id'), A_id', y_id', s_t')
S_id' <- RandBasis(ExtBasis(S_id, A_id'), s_t')
```

并紧接着说明：当新身份已经处于最大深度 `t' = d` 时，不需要生成 `S_id'`，因为它只用于继续提取后代密钥。也就是说，最大深度叶节点的合法最小路径是：

```text
一级 RandBasis
→ ExtBasis(S1, A2)
→ SampleD(ExtBasis(S1, A2), A2, y2, s2)
→ 缓存叶节点原像
```

因此，二级叶节点不调用第二次 `RandBasis` 是论文允许的终止层优化；它不是为了绕过资源限制临时删除步骤。若二级节点还要继续派生后代，则必须生成二级 `RandBasis`，不能使用本契约。

## 2. 代码对应

当前研究审计 `experiments/research/chkp_leaf_audit.py` 在一级完成 `RandBasis` 后，对二级执行 `ext_basis(basis, block)` 并直接构造 `CHKPGPVSampler(expanded, width, ...)`。二级分支只调用叶原像批量采样，不实例化 `CHKPRandBasis`。

新增回归测试对 `CHKPRandBasis` 计数：固定种子下成功路径只调用一次，调用发生在一级；二级调用数为零，两个二级目标均通过精确方程检查。这验证的是当前代码的路径结构，不是对全部正式参数的安全证明。

## 3. 与 §5.3 和缓存的关系

第 22 页 §5.3 的 `ROHIBE` 把身份映射为

```text
A_id = A0 || A1 || ... || At
y_id = G(id)
```

并要求同一身份重复查询时返回同一个 `x_id'`。因此，叶节点原像缓存是后续 T3 的必要状态机制；它不能用“每次使用同一个测试随机种子”代替。当前缓存阶段已经验证了固定目标和私有快照恢复，但 H/G、真实身份编码和字节载荷仍未接入。

## 4. LLL 后处理的边界

当前四个固定种子的成功叶路径保留了一级 `RandBasis` 后的可选精确 LLL。LLL 产生同一格的另一组完整基，属于本项目的确定性后处理，不是 CHKP §5.2 的 `RandBasis` 原文步骤。

因此必须分开记录：

- 原文路径条件：最大深度可以省略二级 `RandBasis`，但 `SampleD` 必须使用扩展后的一级基。
- 项目实现条件：当前采样器在无 LLL 的对照下因标量宽度准入拒绝；加入 LLL 后，小参数四个种子通过。
- 尚未闭合的理论条件：需要为正式参数证明或估计一级后处理输出的 GS/普通范数界，并把后处理带来的失败预算计入整链账本。

LLL 通过不能被写成“论文证明了当前实现一定通过”，也不能把无 LLL 的失败隐藏掉。

## 5. 当前验收结果

| 检查 | 结果 |
|---|---|
| 原文终止层条件 | §5.2 PDF 第 20 页明确允许不生成最大深度 `S_id'` |
| 二级路径 | 使用 `ExtBasis(S1,A2)` 直接 `SampleD` |
| 二级 `RandBasis` | 0 次调用；回归测试固定 |
| 固定种子、小参数、一级 LLL | 4/4 叶路径通过，8/8 原像方程通过 |
| 无 LLL 对照 | 0/4，二级 `SampleD` 宽度准入拒绝 |
| 正式参数 | 尚未确定，必须重新核验 |
| 安全声明 | `security_claim: none` |

## 6. 未闭合项与下一步

本契约已经闭合“是否可以省略二级 RandBasis”这一原文路径问题，但没有闭合整个 T2。剩余工作按以下顺序进行：

1. 对正式候选参数重新计算一级后处理后的 GS 界、`s2`、原像范数、随机带和中止预算。
2. 判断 LLL 是否只是研究诊断，还是正式实现必需；若必需，补齐其资源/失败分析。
3. 用同一组合法参数重跑根→一级→二级叶原像链，保留所有拒绝结果，不搜索成功种子。
4. 把目标从测试用 `(0,)`、`(1,)` 换成真实 `G(id)` 后，再进入 T3 的完整 HIBE 生命周期和缓存接入。
