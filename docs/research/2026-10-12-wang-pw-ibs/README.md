# Wang 基本 IBS + Pan–Wagner 转换：独立实现入口

更新：2026-10-13。请先看[修复与验收报告](../2026-10-13-wang-pw-audit/README.md)。

原交付能够完成签名验签，但独立审查发现用户密钥携带主陷门、发钥未真正使用主陷门、GPV 公式错误、公钥哈希绑定不完整及解析边界问题。原来的“28 项通过”和“带扰动采样已经正确实现”不能作为验收结论，旧版结果仅保留作历史反例。

本轮已经直接修正独立代码。当前实现路线是：

```text
Setup：生成公共矩阵 A 与主陷门 R_A
KeyExt：用 R_A 生成完整核基，再用 GPV 采样得到该身份的委派陷门 R_x
Sign：仅用用户 R_x 生成完整核基，以 GPV 采样消息原像
Verify：检查非零、范数和模方程
PW 外层：独立发钥生成身份盐 r；同一份密钥签名时复用 r，每次签名重新取消息盐 s
```

对应实现见 [wang_pw.py](../../../src/ibme/ibs/wang_pw.py)。用户拿到的密钥不含主陷门；纯函数 `key_extract_pw/sign_pw/verify_pw` 可以脱离发钥服务使用。另有按身份缓存密钥的 `WangPWScheme` 便利服务。

采样采用 MP12 Lemma 5.3 的陷门转完整基方法和 GPV08 §4.2。它不是 MP12 Algorithm 3 的扰动采样，不再保留旧版舍入 Cholesky 路径。LLL 只负责保持整数格不变的基规约，不能替代高斯采样。

整数线性代数采用精确运算；标量高斯采用有限窗口、80 位 Decimal 权重及 128 位接受阈值，属于有资源上限的数值实现。分布误差和宽度安全条件不能由模方程或功能测试代替。

本轮只完成单体实现核验，不处理公共接口、正式参数或 HIBE 组合。使用小参数测试，保留 `security_claim=none`、`parameters_are_formal=false`、`backend_admitted=false`。准确测试数量、命令、哈希和证据见上面的验收报告。
