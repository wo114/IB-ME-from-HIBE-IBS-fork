## 3. 术语表

| 术语 | 本项目采用的含义 | 需要防止的混淆 |
|---|---|---|
| ME | 双方分别指定匹配条件的匹配加密 | 不等同于只有接收者访问控制的普通加密 |
| IB-ME | ME在身份等值匹配策略下的形式 | 不等同于所有属性策略或所有隐私模型 |
| $\phi$ / $\mathrm{snd}$ | 发送密钥绑定的身份 / 接收者解密时选择的发送者身份 | 前者是密钥关联身份，后者是算法输入 |
| $\rho$ / $\mathrm{rcv}$ | 接收密钥绑定的身份 / 发送者加密时指定的接收者身份 | 两者相等是合法匹配的一部分 |
| 双向身份匹配 | $\rho=\mathrm{rcv}$且$\phi=\mathrm{snd}$ | 不自动提供在线认证、消息回执或会话新鲜性 |
| 系统密钥生成中心 | 运行建立与身份发钥算法的受信任角色 | 不预设恶意中心安全或无密钥托管 |
| 两层匿名HIBE | 具有身份层级、密钥委派和所需匿名安全性质的HIBE | 普通IBE不能只改名称就代替两层接口 |
| IBS | 身份关联签名密钥与身份作为验证依据的签名机制 | 普通数字签名原语不能未经构造转换直接视为IBS |
| 通用构造 | 在组件满足指定条件时组织算法并给出组合结论的方法 | 不等同于一个已经确定参数的具体实现 |
| 具体实例 | 选择具体组件算法、参数与表示方式后得到的方案 | LWE或SIS的名称本身不是完整算法 |
| 隐私性 | 在指定挑战和密钥查询限制下的不可区分目标 | 不解释为对所有持钥用户、系统中心均隐藏所有信息 |
| 强可认证性 | 按博士论文定义3.2.10讨论伪造能力，包括被腐化接收者情形 | 不将“强”理解为自动覆盖所有攻击或所有密文字节变化 |
| 正确性 | 合法输入和满足前提的参数下，协议按定义恢复消息 | 有限样例成功不是一般正确性证明 |
| 格基抗量子路线 | 研究依赖相应格困难假设的构造和实例 | 不能自动继承标准算法等级或未证明的量子查询模型结论 |
| ROM / 标准模型 | 文献证明采用的不同建模条件 | 不以模型名称代替具体安全游戏，不自行升级声明 |
| 参数安全估计 | 在明确攻击模型、输入参数与估计方法下评估成本 | 不等同于正式归约，也不等同于功能测试 |

术语依据主要为正文参考文献[1]、[3]、[5]、[6]、[7]；关于在线会话与信任中心的边界是对算法语义的解释及本项目范围说明。
