# 第二十二步独立复核与直接返工

## 工作分离

- 主Codex：提出鲁棒接受集＋均匀公开矩阵二阶矩证明，完成有方向数值证书、真实候选Sign、恢复／编码和回归审计。
- DeepSeek：第一轮独立检查10条数学主张；第二轮只检查返工后的耦合／预算文字，不把第二轮说成重新实验。
- 参数子智能体：独立运行固定版估计器、核查论文参数表和三个初始profile；追加精确C64B的两项SIS运行。
- 接入子智能体：检查CHKP公共边界，主Codex阅读脚本并再次运行；不修改CHKP或根框架文档。

## 数学意见处理

| 意见 | 主Codex处理 |

| 原任务摘要把几何拒绝帽写得像全部实际中止帽，有限均匀抽样／哈希解码会直接中止 | 接受文字问题；最终正文先定义理想补全过程，再把第一次分离及全部下游差异统一计入坏事件。原型证书已分别列来源项，正文明确不能漏加。 |
| κ(U+1)≤16384不由参数构造器自动保证 | 接受；证书显式逐配置检查。新增κ64、U256的拒绝测试；原两个候选U128都在证明域内。 |
| pS须对包含挑战／响应的完整历史统一 | 明确固定同一个好A后，对所有有效密钥、消息与完整历史使用同一pS；后续掩码理想独立。不是对历史重新挑更有利矩阵。 |
| 外部自适应哈希查询不能无限且不计费 | 已加入QH*dH；作为理论资源预算，不宣称能在程序里登记所有外部离线SHAKE计算。 |

第二轮审查中“U≥QE”“每个挑战必须一个满熵新种子”等附加说法不采纳：U是标量拒绝帽，与身份个数QE没有大小关系；理想独立字节模型没有规定那一种具体播种方法。真实CSPRNG/SHAKE的计算假设仍独立声明，不能凭域分隔把确定性PRG证明成信息论独立。

DeepSeek报告自己枚举2193组LowBits小域和一个小参数端到端30次；这两项是协作者报告，不加进主Codex269测试数。主Codex自己保存了LowBits小域穷举、微型环完整625个公开矩阵的二阶矩检查及定向舍入测试。有限枚举不替代一般数学证明。

## 实验意见处理

- 每个候选先预登记54条call，Setup失败仍保留全部not_run行；Sign中止不会删除该次分母，未知字段不填0。
- 新故障注入检查Setup异常、Sign中止、Verify失败、重复输出目录；这些是账本夹具测试，不当密码算法成功证据。
- C49源码后增加C64B profile与精确Fraction检查，先保存两份原运行脚本快照；不伪造其旧source hash。C64B在修改后的脚本上重新完成全54次。
- C49 compact尺寸第一次测试误写16063，原始probe是16062；保留11通过／1失败的JUnit，再修正到实际值。最终269项单次完整通过；未重写旧实验。
- 打包审计发现协作者C64B JSON转存把预算2^64写成18446744073709552000，而源脚本及主证书是精确18446744073709551616。全部概率分子一致。保留pre-integer-fix副本与首次打包失败日志，按原脚本修复预算元数据，不重写攻击成本或放松等值检查。超2^53的JSON整数必须用任意精度整数读取，不能经JavaScript Number解析后重写。

## 当前判断

鲁棒接受概率下界和有限生命周期中止上界已形成完整条件式推导，并经上述独立质疑修订；精确联合分布仍未知，真实SHAKE安全、完整Luo安全归约及真实CHKP组合不由本定理解决。建议由导师审阅这一新增数学论证；不能称“万无一失”或“Lean已证”。

原始DeepSeek长输出和私人任务书保存在本机deliverables，不将内部推理日志或私人任务单推到GitHub。本页记录可检查的主张与采纳决定；公开证据对应脚本、数据、JUnit及manifest。

归档evidence保留原始CRLF、失败日志缩进和末尾空行，子目录.gitattributes只对此归档禁用Git文本归一化及空白提示，保证stdout收据和Git blob哈希一致。可执行主源码和正文仍执行常规diff检查；不通过编辑失败输出隐藏断言。
