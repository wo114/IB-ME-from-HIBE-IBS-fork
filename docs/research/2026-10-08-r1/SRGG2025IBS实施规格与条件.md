# SRGG 2025 IBS 实施规格与条件

日期：2026-10-08。来源为 [出版社原文](https://ietresearch.onlinelibrary.wiley.com/doi/pdf/10.1049/ise2/6684889)，12 页；本地 PDF 下载仍未成功。本文规定研究对象，暂不把它设为首套实现，不另写 QROM 补证。

## 1. 接口与对象

| 入口 | 依据和对象 |
|---|---|
| setup | §4.1 Algorithm 1；seed 生成公开块，保存模格 master trapdoor/secret、$p,q,Q,b,w,n,d$ 与协方差配置 |
| key_extract | §4.2 Algorithms 2–6；扰动与 gadget 采样，缓存 identity 的短原像；身份摘要和公钥上下文属于对象 |
| sign | §4.3 Algorithm 7；保留离线/在线相序，使用已有用户原像并产生新随机性，输出 $(z,c)$ |
| verify | §4.4 Algorithm 8；检查范数、重构承诺与挑战哈希；坏输入返回 False |
| load_signature | 同一 profile 的规范有符号向量与挑战编码；ANS 只是可选编码，不能把熵估计当作已实现格式 |

原文 Definition 3 缓存取钥和签名状态，研究实现必须保持这一语义。高斯参数中出现“标准差”和原文密度宽度两套记号时显式转换，不直接复用现有 MP12 参数的数值。

## 2. 两项不能跳过的引用条件

首先，Theorem 2 是带底层 **sEUF-CMA** 条件的 IBS 结论；Theorem 1 的陈述是 EUF-CMA。需定位底层强结论及适用条件，不能凭同一篇文章出现 Theorem 2 就假定前提已经满足。

其次，PDF 第 4 页 Theorem 1 的模数条件含 $q>2\gamma$。§5.1 的 IBS 使用 $Q=15744063$，Table 4 的三个 $\gamma$ 均大于 $Q$。如果直接令底层 $q=Q$，或将整个模数 $2Q$ 当作 $q$，三组均不满足该字面条件。**尚未确认两节参数映射，因此这是待澄清的条件，不是新伪造攻击或方案不安全的定论。** 未澄清前不直接复制这些点作为满足该定理的安全后端。

该问题通过代入原文条件即可发现，工作范围仍是引用核验；不把修补底层理论变成本项目主任务。

## 3. 尺寸与工程成本

Algorithm 1 对应的非单位公开块有 $d\times wd$ 个环元素。用 $n=512,w=2$、24 bit 模系数及 32 B seed，裸公开块容量为 $32+24nd^2w/8$，对 $d=2,3,4$ 得到 12320、27680、49184 B，与 Table 4 相符；Table 1 的较小公钥和签名数值尚无同一规格的解释。[参数核验](parameter-checks.json)

公开块计数不包含项目配置头。私钥/签名的 ANS 容量与浮点 C 原型计时仍是作者报告，未在本机复现。公开代码本轮未取得；如果继续实现，应先冻结固定宽度参考编码、实际长度和采样依赖，再讨论压缩。

## 4. 本轮结论

SRGG 继续作为直接 IBS 候选，**引用条件尚未满足，暂缓首套实施和安全准入**。配置仍标 `security_claim: none`。取得明确参数映射和底层强结论后再进入真实采样实现；当前不安排队友独立重证整篇论文。
