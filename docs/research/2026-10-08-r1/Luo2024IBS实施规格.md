# Luo 2024 IBS 实施规格

日期：2026-10-08。原文为 [ICICS 2024 固定稿](../../../papers/2024_ibs_without_trapdoors_luo.pdf)，20 页。先实现 §3 的矩阵研究参考，再处理 §4 的模格压缩版本；两者的公开参数、哈希和格式分别版本化。本文不是补写整篇安全证明。

## 1. 矩阵参考的接口对应

| 入口 | 论文算法/本项目适配 |
|---|---|
| setup | Algorithm 1：$A\in\mathbb Z_q^{n\times m}$、秘密 $S\in[-\eta,\eta]^{m\times k}$、$T=AS\bmod q$ |
| key_extract | Algorithm 2：采样均匀整数掩码 $Y$，$W=AY$，$C=H_1(W,id)$，$Z=SC+Y$；仅当 $\|Z\|_\infty\le\gamma_1-\beta_1$ 接受 |
| sign | Algorithm 3：新均匀整数掩码 $y$、$c=H_2(id,Ay,M)$、$z=Zc+y$；严格 $\|z\|_\infty<\gamma_2-\beta_2$；返回 $(z,c,W)$ |
| verify | Algorithm 4：重算 $w'=Az-(W+TH_1(W,id))c$，核对严格范数与 $H_2(id,w',M)=c$ |
| load_signature | 规范解析有符号 $z$、稀疏挑战 $c$ 和模矩阵 $W$；维度、系数范围、字段顺序、截断/追加都检查 |

签名密钥保存身份及完整公钥上下文，`sign(sk,message)` 不接受另一个身份。真实 IBS 哈希只用该 IBS 的公开参数、身份和消息等规范输入，角色域分离；不隐式引入 HIBE 公钥依赖。组合已有的上下文优化只能复制相同输入的计算状态。

H1 输出矩阵的列挑战范数与 H2 的稀疏向量挑战按原文约定实现，矩阵 1-范数不能误解释成所有元素绝对值的总和。由无偏组合抽样与符号抽样实现，不用 `%` 产生有偏索引。掩码为均匀整数是原文算法的真实要求，**不是用均匀数冒充 Gaussian**。

## 2. 固定密钥的引用解释

Algorithm 6 的签名模拟调用 Extract Oracle，PDF 第 9 页外层模拟描述对所有 Extract Oracle 查询保留缓存并重复返回。研究实现将这个命名 oracle 统一解释为有状态的 oracle，签名内部调用也查询同一张表；真实发钥、签名与恢复共用一份用户状态。

这是本轮采用的**原文引用解释**，没有完成独立的全证明复核，也没有宣称疑点已由作者确认。若后续取得作者代码或修订稿，与此语义冲突，停止安全准入并记录冲突，不默认改成每条消息重新发钥。数学研究实现可按此状态语义推进，生产结论仍需引用条件和参数对应。

引用 §2.2、Theorem 1 和 §4.4 时只使用其声明范围：普通自适应 EUF-ID-CMA、经典 ROM；模格有 MLWE 和 MSIS 依赖。原文关于量子 Fiat–Shamir 的讨论不能作为本项目完整 QROM 定理。

## 3. 首轮研究参数与测试

配置见 [luo-matrix-research.json](luo-matrix-research.json)：$n=4,m=8,k=4,q=65537,\eta=1,\kappa=2,\gamma_1=128,\beta_1=2,\gamma_2=2048,\beta_2=256$。身份上限 16 B、消息上限 32 B。它仅用于真实算法方程/生命周期参考，不提供 SIS 难度或任何安全位数，`security_claim: none`。

R2 检查主公钥方程、发钥关系、签名方程和严格范数边界；一个身份连续签多条不同消息，签前/签后取钥与跨进程恢复保持 $Z,W$；新掩码不能复用。验证拒绝身份/消息替换、维度错误、非法稀疏挑战和非规范编码。采样器有公开资源上限及明确中止，不能越限后返回默认签名。

先放入 `experiments/research/luo_matrix_reference.py`，不替换旧 SisIBSBackend，不注册安全后端。数学参考通过后，增加独立 `src/ibme/ibs/luo.py` 适配及 contract tests；是否计完整实例以真实协议和参数验收为准。

## 4. 模格版本的实际参数缺口

Algorithms 13–16 与 Table 1 需一并实施。原文只列模数的对数，未给精确 $q$；UseHint 使用 $(q-1)/(2\gamma_3)$，需要核对整除和 $q>2(2\gamma_3)$，NTT 还需合适根。

在把 Table 1 的 34/36/38 解释为 bit 长度、令 $2\gamma_3=\gamma_2$、要求 $q$ 为素数和 $q\equiv1\pmod{512}$ 的条件下，Sage 只找到第一行的一个素数候选 $14952038401$；第二、三行的该区间候选均为合数。**这是条件式选参核对，不是对论文的攻击，也未认定作者用了该解释或该模数。** 完整候选见 [参数核验](parameter-checks.json)。

因此先做不依赖 Hint 压缩的 §3 矩阵参考；§4 要明确精确模数或重新选取满足原文一般条件的研究配置并重新估计，不直接复制表格声称复现其安全位数。Table 1 的第二行 BKZ 指数按作者模型为经典 137.240、量子 124.550，且未计查询损失，不自动是 128 位量子实例。

Algorithm 15 第 9 行出现 `zid`，其与该算法的签名变量 $z$ 的对应、Extract 与正文边界比较区别，均在实现注释中定位原文；只修明确记号问题，不改数学接受范围。首轮不为了速度调整秘密/噪声、挑战分布或验签条件。
