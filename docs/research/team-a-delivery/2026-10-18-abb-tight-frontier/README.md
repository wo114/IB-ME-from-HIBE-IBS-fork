# ABB-ROM 紧参数前沿：最小 AP09 维度与有限矩阵 Bernstein 界

本批得到一个比原 `n9600/q208/qα=721` 锚点明显更小、且按 `2^20` 次服务规模重新记账的 ABB 研究参数：

```text
candidate = abb-rom-tight-n8224-q180-chi721
n         = 8224
q         = 1532495540865888858358347027150309183618739122183602129
bitlen(q) = 180
d=m1      = 1973761
m2        = 6908162
m         = 8881923
q*alpha   = 721
```

它是本批固定网格中第一个同时满足条件正确性、有限噪声服务账本和四个密文 LWE 比较模型 128 门槛的点，密文侧最低估计为量子 primal-uSVP 的 `128.790 bit`。它仍只是**实现研究候选**：根陷门 SIS 比较器没有有限返回，完整 ABB 有限采样/归约映射尚未完成，而且完整父基和原始 32 B 密文仍分别至少约 `473.3 TB` 和 `52.3 GB`。因此正式双侧候选和完整运行候选均为 0。

## 本批改变了什么

没有更换 ABB 算法，也没有只改同一算法的传输压缩。改动是两项适用于当前 AP09/ABB 构造的公开上界收紧。

第一，AP09 构造器实际要求 `d>n·ceil(log2 q)`、`m2>=2nk+2d` 和 `m=d+m2>6nk`。旧投影固定 `d=2nk`，得到约 `m=8nk`；本批逐整数选择满足全部 LHL 和严格维度条件的最小 `d`，推荐点得到 `m=8,881,923`，只比严格 `6nk` 下界多 3。

第二，旧投影用支持集 Frobenius 界 `m²·radius²` 上界随机 SampleR 的谱范数平方。新投影直接对有限采样器在成功条件下的独立、中心对称、有界标量输出应用矩形矩阵 Bernstein：推荐点的谱范数上界为 `73,132,956,277,301`，平方界比旧支持界小约 `25,271` 倍。单矩阵无条件事件留 `150 bit`，经可逆条件化留 `149 bit`，再对 `2^20` 次矩阵调用联合后留 `129 bit`。

可逆条件化不再只是未核验假设。有限标量证书给出接受质量下界，故成功条件下单个剩余类的最大点概率有显式上界。对逐列生成的矩阵，每个新列落入已有真子空间的概率不超过该最大点概率；推荐点的奇异概率联合上界约 `0.0500794`，可逆概率下界约 `0.949921`。每次 SampleR 最多 35 个完整矩阵尝试后，`2^20` 次服务的秩失败联合界低于 `2^-130`。有限标量 TV 同时对标量成功和矩阵可逆两次条件化保守放大 16 倍。

## 服务级正确性与有限噪声

旧卡的 `error_bits=128` 是单个加密比特事件；乘以每次 256 bit 和 `2^20` 次封装后，生命周期界只有 `2^-100`。本批把单比特事件提高到 `158 bit`，使理想噪声的服务联合界为 `2^-130`。同时实际构建新的舍入连续 Gaussian CDF：

```text
tail_bits     = 224
mass_bits     = 320
precision_bits= 384
radius        = 10815
support_count = 21631
draw_bytes    = 40
CDF SHA-256   = 0c1141ca50e88cf3084a9a18704186010536ca84e6eb44a74ec60771b79b5d4c
```

有限 CDF 的 TV 按每个密文比特 `(m+1)` 个新噪声标量、256 bit 和 `2^20` 次封装聚合。推荐点的密文噪声联合界约为 `2^-130`；SampleR 范数事件、有限 TV 和秩失败合计约 `2^-128.714`；两部分再联合约 `2^-128.218`，仍低于 `2^-128`。这个账本尚不包含 BasisDel、RandBasis 和 SamplePre 的全部有限 TV、范数事件与运行失败，所以不能升级为完整正确性或安全证明。

## 固定网格结果

估计器固定为 lattice-estimator 提交 `53da5982597709ba0fdf94ea37a84d822310fd84`，成本模型为 ADPS16 classical/quantum Core-SVP。密文侧运行 primal-uSVP LGSA 和 plain dual；根侧运行条件式单列 Euclidean SIS 比较器。

| n / q bits | m | 服务正确性最大 qα | 条件正确性 | primal C / Q | dual C / Q | 密文最低 | 实现研究门 |
|---:|---:|---:|---|---:|---:|---:|---|
| 8192 / 179 | 8,798,210 | 705 | 失败 | 142.204 / 129.055 | 346.604 / 314.555 | 129.055 | 未过 |
| 8192 / 180 | 8,847,363 | 1462 | 通过 | 141.036 / 127.995 | 343.976 / 312.170 | 127.995 | 未过 |
| 8224 / 180 | 8,881,923 | 1419 | 通过 | 141.912 / 128.790 | 345.728 / 313.760 | 128.790 | 通过 |
| 8704 / 180 | 9,400,323 | 913 | 通过 | 153.300 / 139.125 | 372.008 / 337.610 | 139.125 | 通过 |

第一行说明 q179 在旧单事件口径下看似可用，但按完整服务口径会违反正确性；第二行说明只把模数升到 q180 又会使同一 n 的密文比较成本降到门槛下。`n8224/q180` 是两条约束在固定网格中的第一个交点，`n8704/q180` 则保留更多比较余量。

四行根侧经典和量子 SIS 调用均返回 `rop=+Infinity`，机器可读状态严格记录为 `no_finite_estimate` 和 `null`，不是无限安全成本。推荐点的比较器内部为 `β=d=258427`；它只覆盖“一列不同有界原像导出一个 SIS 向量”的必要子问题，未覆盖植入原像恢复、全部 R/完整陷门恢复或共享矩阵多目标摊销。

| 固定维度 m | 15,974,400 | 8,881,923 | 55.60% | 44.40% |
| 单份完整基编码下界 | 1,531,088,732,160,000 B | 473,331,337,067,574 B | 30.91% | 69.09% |

这已经把 PB 级完整基降到数百 TB，但没有让当前实现可运行。当前消费者仍展开完整 `m²` 基并有 `m³` 访问；有限 SampleR 每个标量的固定公开带为 `3,026,760 B`，推荐点一次 35 尝试的字节带上界约 `8.36×10^21 B`。这些数值本身就是拒绝直接放宽资源 guard 的证据。

## 执行证据与安全声明

正式公开运行使用本机 Nix Sage 10.9 / Python 3.14.7、Linux 6.18.56、12 逻辑 CPU。总时长 `37.030 s`，CDF 构建 `1.088 s`，进程最大 RSS `301,408 KiB`。运行只做公开整数/有理数计算、CDF 和攻击比较；根、基、私钥、密文生成数均为 0，私有随机字节为 0。

完整参数、每个精确失败界、估计器原始字段、源码散列和基线卡散列见 [parameter-card.json](parameter-card.json)，运行摘要见 [runtime-summary.json](runtime-summary.json)，复现命令见 [commands.md](commands.md)。

所有输出保持 `security_claim=none`、`backend_admitted=false`、`parameters_are_formal=false`。本批没有宣称 NIST 等级、标准模型或 QROM 安全，也没有把比较模型、功能测试或有限采样账本当成 ABB/HIBE 安全证明。下一处真正有价值的工作是补 AP09 植入短原像/完整根陷门恢复的适配攻击口径，以及寻找不展开完整随机化基、同时保持 ABB BasisDel/SamplePre 分布语义的算法或表示；直接运行本参数仍不合适。
