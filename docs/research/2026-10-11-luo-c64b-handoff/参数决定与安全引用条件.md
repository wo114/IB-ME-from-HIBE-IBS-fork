# C64B 参数决定与安全引用条件

任务启动于2026-10-11，核验跨至2026-10-12。这里只决定 Luo 单体及可运行研究组合的候选输入，不替团队决定最终三组算法。

## 1. 本轮决定

**选定 C64B 为接下来的固定研究候选。** 数值选择门槛不再写成“继续盲扫参数”；`profile.json` 和 `c64b_params()` 是一致的17字段快照。旧默认及 C49 对照不删除、不静默替换。正式安全等级没有授予，`parameters_are_formal=false` 不改名绕过。

可执行判定器28项通过，核对归档哈希、参数一致性、舍入/Hint条件、精确中止证书、两分支见证界、挑战空间及已运行的估计输入。`python -O` 下也通过；历史损坏的 QH 大整数作为负例退出2。它不重新运行估计器，也不是28个安全定理。

选择的实际权衡：保留κ64的挑战空间，并取得可用性条件界；代价是共同MSIS启发式成本较旧默认下降、compact增加320 B、最坏重试帽增加。没有声称所有指标同时更优。

## 2. 引用条件逐项落地

原文为 Luo、Chen、Susilo、Huang，*Identity-Based Signature from Lattices without Trapdoors*，ICICS 2024。页码使用论文印刷页码（PDF第1页为p1）。[会议原文](https://icics2024.aegean.gr/wp-content/uploads/2024/08/150570198.pdf) §4.1–4.3 用于算法/正确性，§4.4（p15–16）为安全归约草图。

| 条件 | C64B及实现的对应 | 结论类型 |
|---|---|---|
| 环与舍入：§4.1，p11–12 | N256，q素性复用Sage证据；α=2γ3，q−1=5α，q>2α，NTT根关系满足 | 数值已核对 |
| 掩码与挑战：Algorithms13–16，p13–14 | η1、κ64；β1=64、β2=12160000；γ1>β1、2γ2<q；真实均匀有界掩码，不是高斯 | 参数及源码对应 |
| 正确性/Hint：§4.3，p14–15 | γ3>β2，κ2^(d−1)=8589934592<γ3；保留完整舍入/Hint步骤。身份密钥界使挑战乘积严格小于β2 | 引用一般引理，数值满足；测试另列 |
| γ3独立选择：Table1，p15 | 本地γ3=(q−1)/10，不等于表中γ2/2；仍满足上述一般条件 | 是参数变体，不继承作者表格等级/尺寸/平均重试 |
| 挑战空间：§4.2，p13 | κ64使log2空间≈267.567；大于作者“希望128至256”的设计目标，但未违反挑战定义 | 设计目标差异，不是已发现算法矛盾；133.783仅泛型量子搜索尺度 |
| A的生成：§4.1与Algorithm13 | 使用完整显式均匀A，直接对应算法的理想抽样；未使用工程seed+SHAKE-128压缩 | 不宣称短seed展开与全体均匀矩阵信息论同分布；尺寸不能照抄作者 |
| 固定身份密钥：§3.2及§4.4的引用 | 同一身份返回缓存中的同一把密钥；缓存与主状态恢复已有实现证据，帽64；调用历史遵守单写者状态约定 | 真实实现对应不替代原文模拟论证；反回滚等运行假设仍披露 |
| 已见/未见标签及见证：§3.2、§4.4式(4.1) | 分支以哈希标签而非仅身份划分；已见[A\|I]，未见[A\|I\|t]；新标签可能属于已签身份 | 见证界已核对；采用原文模拟/分叉论证的条件层级，不伪造紧性/优势公式 |
| MLWE/MSIS困难性 | 使用第二十二步固定版本模型结果，说明无结构系数格启发式及遗漏攻击范围 | 估计，不是数学困难性下界；不能推“整个IBS128位” |
| H1/H2与SHAKE | 角色域、公钥上下文、身份与消息规范编码明确；理论仍按经典理想RO/XOF解释，真实SHAKE-256为实例化假设 | 不证明SHAKE等于真随机，不增加QROM结论 |
| 有限采样中止 | 实际uniform帽128、Extract/Sign帽4096；总界对应一次Setup、QE≤64、QS≤65536、经典新鲜QH≤2^64 | 项目新增条件式可用性推导；不是Luo原文给出的数值，也不是安全位数 |

`[A|I|t]` 的 t 是一个环列，系数展开增加256列，不是增加2816列。相应两分支为2816×5376与2816×5632；共同无穷范数放松界127155326978。原文所需不同分支的非零与模拟前提必须随引用保留，不用“测试没有找到伪造”代替。

## 3. 可以直接用于报告的措辞

本项目按 Luo 等人模格 IBS 的算法及经典随机预言机模型下安全分析组织理论依据，并对具体参数、固定身份密钥、规范编码和实现差异逐项核对。C64B是项目选定的研究参数变体，不直接沿用原文表格中的安全位数。我们给出独立的MLWE/MSIS攻击成本估计、有限预算下的条件式采样中止界和实现验收；三类证据不互相替代。在原文所采用的困难性与模拟条件以及所述RO实例化假设下，使用其条件式安全论证，不宣称新增完整归约、紧性或QROM安全。

第二十二步给出的生命周期中止界，在其理想模型、好矩阵例外集与指定正常调用预算下小于2^-153；真实SHAKE、系统熵源失败、缓存越限、存储故障与回滚等并不因此获得无条件保证。精确LowBits联合分布仍未知，但不是该条件界成立所必须求出的量。

模型假设是声明的边界，不是靠再跑几轮功能测试就会消失的问题。更改C64B数值、采样帽、缓存策略或编码时，应重新生成相关证据并使用明确的新配置，而非继续借用此次记录。
