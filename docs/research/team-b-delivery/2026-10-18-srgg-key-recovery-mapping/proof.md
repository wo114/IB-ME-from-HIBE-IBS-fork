## 每一列的精确方程

设论文 Table 4 的 `n=512`、模块秩 `d∈{2,3,4}`、`w=2`、`Q=15744063`，环 `R_Q=(Z/QZ)[X]/(X^n+1)`。Algorithm 1 定义 `C=[I_d|Â]∈R_Q^{d×2d}`、`R∈R^{2d×wd}`、`F=I_d⊗p[1,b]∈R_Q^{d×wd}`、`B=F−CR (mod Q)`；公共对象保存种子和 `B`。代码对应 `paper_backend.py:118–133` 的种子、CBD1 `witness`、接受过滤与 `PublicKey`；`structured_execution.py:193–208` 的 gadget、`build_public` 正是该式，`paper_objects.py:60–81` 核对种子展开的 `Â` 和规范公共对象。

固定任意一列 `j∈{0,…,wd−1}`，写 `R_j=(e_j,s_j)`，两段各有 `d` 个环元素。令 `t_j=F_j−B_j`，则**逐列恒等**

`Â s_j+e_j=t_j (mod Q)`。

将每个环元素按系数展开为长度 `n` 的整数向量，令 `m=dn`，把 negacyclic 乘法矩阵组成 `M_Â∈Z_Q^{m×m}`。于是 `M_Â vec(s_j)+vec(e_j)=vec(t_j)`。按作者的顺序，此列的公开格映射是 `[M_Â|I_m|vec(t_j)]`；`(vec(s_j),vec(e_j),−1)` 在其模 `Q` 整数核中。由于中间块是 `I_m`，该映射到 `(Z/QZ)^m` 满射，即使 `Q` 合成、`Â` 非满秩仍成立。核在 `Z^{2m+1}` 的指数和行列式**精确**为 `Q^m`。这只建立格输入和一个诚实见证的存在，不给 BKZ 成本或完整主密钥恢复概率。总共有 `wd=2d` 列；任意短核向量的末坐标可能为 `0` 或其它整数，末坐标即使为 `−1` 也只给该目标的一个解，未证明它等于原始 `R_j`、符合 CBD1 支持或满足整矩阵 Setup 门。只有确实找回原始列时才可称恢复该列，更不能由一列直接称恢复整个 `R`。

## 同一公开对象的多目标联合格

Algorithm 1 的所有 `wd` 列共用 `Â`。令 `k=wd=2d`，把公开的 `vec(t_j)` 并为 `T∈(Z/QZ)^{m×k}`。除了论文 §5.2.2 印出的单目标格，还可**从同一公开对象推导**多目标整数核格

`Λ_joint = { (s,e,u)∈Z^(2m+k) : M_Â s+e+T u=0 (mod Q) } = ker_Q([M_Â|I_m|T])`。

对每列 `j`，若 `u_j^(k)` 是 `Z^k` 的第 `j` 个单位向量，则 `(vec(s_j),vec(e_j),−u_j^(k))∈Λ_joint`；这些诚实向量的任意整数线性组合也在格中。`I_m` 仍保证到 `(Z/QZ)^m` 满射，因此 `D_joint=2m+k`、`det Λ_joint=Q^m`，与 `Q` 是否素数及 `Â` 的秩无关。三档维数分别为 `2052/3078/4104`。

上述 `T` 仍是 `k` 个**环列**。若把每个列目标的 `n` 个乘 `X^a` 旋转也视为公开输入，定义 `M_T∈(Z/QZ)^{m×kn}` 为环映射 `u∈R_Q^k ↦ Σ_j t_j u_j∈R_Q^d` 的系数矩阵，则另有

`Λ_ring = { (s,e,u)∈Z^(2m+kn) : M_Â s+e+M_T u=0 (mod Q) } = ker_Q([M_Â|I_m|M_T])`。

对 `0≤a<n`，以 `u_(j,a)^(kn)` 表示末段第 `(j,a)` 个单位向量；`(vec(X^a s_j),vec(X^a e_j),−u_(j,a)^(kn))∈Λ_ring`，因为环乘法可交换，`Â(X^a s_j)+X^a e_j=X^a t_j`。乘 `X^a` 在 `R=Z[X]/(X^n+1)` 的系数上是带符号置换，保持欧氏范数；这 `kn` 个诚实见证的末段各有不同单位坐标，因而线性独立。`I_m` 再次保证满射，所以 `D_ring=2m+kn=4m`，`det Λ_ring=Q^m`，三档维数为 `4096/6144/8192`。把末段只限于每个环列的常数项，就回到上面的 `2m+k` 截面；仅保留一列的所有旋转则得 `2m+n` 维输入。

## 诚实 CBD1 范数和 Setup 条件化

论文 §5.1 指定 `χ={−1:1/4,0:1/2,1:1/4}`。实际 `paper_backend.py:120–130` 每次尝试从每字节的两个低位相减构造 `R`；**若提议字节独立均匀**，一列 `2m` 个系数独立 CBD1，`||R_j||²≤2m`，`E||R_j||²=m`，见证 `(s,e,−1)` 满足 `1≤L²≤D`，未过滤的均方根尺度 `sqrt(E L²)=sqrt(m+1)`。不依赖该理想字节假设的实现事实仅是系数支持在 `{−1,0,1}`。后端只接受原扰动形状的正定根：拒绝循环会对 `R` 作条件化，虽然 CBD1 支持界仍有效，系数独立性及 `E L²=m+1` **不能直接迁移到已接受根**。接受根的完整条件范数分布、与公共 `Â,B` 的联合 law 仍为 null。现有 [Setup 接受审计](../2026-10-18-srgg-setup-acceptance/README_zh-CN.md)及[后端差距](../2026-10-18-srgg-setup-backend-gap/README_zh-CN.md)不能填补这个输入。
