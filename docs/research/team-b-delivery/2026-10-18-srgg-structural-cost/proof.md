# Exact scope of the structural-cost certificate

Source: frozen Jia–Liu–Tang–Wang PDF, Theorem 1 on PDF p.4; Algorithms 7–8 on PDF pp.7–8; §§5.2.1–5.2.3 and Tables 4–5 on PDF pp.9–10. The prior [CRT/HNF preflight](../2026-10-18-srgg-source-schur/hardness-preflight-current.json) independently factors `Q` and `X^512+1`; the [verification-image audit](../2026-10-18-srgg-verification-image/README.md) checks the full unrestricted map. This package does not edit either result.

Write `R_Q=(Z/QZ)[X]/(X^n+1)`. The original public matrix is `A=[I_d|Â|B]`, with `(2+w)d=4d` module columns. For an identity-block column and coefficient index zero, choose the integer vector `v=Qe_i`. It is nonzero over integers, `Av=0 mod Q` for every `A`, and `||v||₂=Q`. Conversely, for a vector supported in that one identity-block coefficient, `A(ke_i)=0 mod Q` requires `Q|k`; thus `Q` is the smallest possible nonzero absolute scalar for this restricted support. Since each published `2γ>Q`, the search problem “find any nonzero integer kernel vector shorter than `2γ`” has an explicit zero-BKZ solution. Dense serialization writes `(4d+1)n` coefficients; sparse representation writes one nonzero coefficient. These are operation descriptions, not calibrated CPU cycles.

The actual verifier matrix is `[2A | Qζ*e₁−2h] mod 2Q`. For each of the first `4d` response polynomials, `2A(Qe_i)=2Q(Ae_i)=0 mod 2Q`. This does **not** assert the final column has the same property. If `z` is already a valid response for a fixed identity/message/challenge, replacing one eligible coefficient `x` by `x−sign(x)Q` leaves the recovered commitment and challenge unchanged. The norm-square change is `Q²−2Q|x|`. Taking a largest-magnitude eligible coefficient minimizes the new norm among single `±Q` shifts. The paper's norm test accepts exactly when `S+Q²−2QM≤floor(γ²)`. If `||z||₂≤γ−Q`, triangle inequality gives a sufficient condition for *any* one-coordinate `Q` shift. Neither condition establishes the probability that an honest signature falls there. The standalone public-kernel construction alone is not an IBS forgery.

The scalar coefficient CRT `Q=3·31²·43·127` sends `Qe_i` to zero in each component. Ring factor degrees over the corresponding residue fields are `256,32,256,8`. Their small degree must not be read as work factor. The degree-eight sparse subring with `Y=X^64` embeds isometrically into coefficient space, but the linear projection keeping coefficients indexed by multiples of 64 is not multiplicative: `P(X)=P(X^63)=0` and `P(X·X^63)=Y`. This blocks the naive projected MLWE equation. True factor-quotient maps are multiplicative; converting a factor-level attack into a bounded full-ring witness requires a lift and norm analysis that is not supplied. Conditioned Setup-root and seeded-matrix laws require separate handling.

Route accounting for this issue: (1) direct reproduction of the paper's generic Core-SVP numbers cannot be promoted to original-ring attack costs without a matching attack model, distribution, and norm-to-BKZ mapping; no estimator was invoked. (2) The universal `Qe_i` route gives an exact, restricted MSIS/kernel cost and a conditional native-strong replacement test. (3) The degree-eight sparse-subring route yields the explicit multiplicativity counterexample, so no subfield attack cost is asserted. No fourth route or blind parameter search was used.

The author-reported Table 5 key-recovery and approximate-CVP forgery estimates target different tasks from the `Qe_i` kernel search; this certificate neither reproduces nor refutes their numeric BKZ outputs. Theorem 1's sufficient `q>2γ` fails if `q` maps to original `Q`, but source notation and the actual IBS reduction still need a separate proof audit. The observations do not determine a NIST category, actual accepted-root attack success, or complete native-strong security.
