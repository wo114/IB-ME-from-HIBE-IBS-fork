# SRGG H1/H2 地址与有限拒绝的经典耦合（WIP）

范围仅为独立 SRGG IBS 的原 Table 4 三行。冻结来源是 `papers/2025_efficient_ibs_jia.pdf`，SHA-256 `258583c5b90255afe91343a282cb62840198b1192b6462dfc9597a24f8c01152`。论文 Table 3（PDF p.6）定义全局 `H:{0,1}*→R_Q^d`、`H̄:{0,1}*→{0,1}^n`；Algorithm 2 p.7 使用 `H(id)`，Algorithm 7–8 p.8 使用 `H̄(w,μ)`。本文件的耦合引理是**额外的经典理想 oracle 条件推导**，并非论文已给出的实际 SHAKE 或 QROM 定理。

**多公钥差异。** 实现地址是 `H1(P,id)` 与 `H2(P,w,μ)`，而论文写全局 `H(id)`、`H̄(w,μ)`。即使在理想 oracle 中，对固定一个、不依赖 H1/H2 的公钥，前者各自的边缘分布可重命名为后者；对两个不同公钥，同一个 `id`（或同一 `(w,μ)`）在实现中访问不同地址并得到独立输出，而原文全局函数对该输入只给一个输出。因此**跨公钥联合游戏不等价**。当前经典单公钥重命名不得直接用于多用户、多公钥或 QROM 归约。

**公钥确定顺序不能省略。** 即使最终只公布一份公钥，先查候选公钥地址、再按回答选择公钥也不能套上段重命名。取同一 Table 4 行中两份不同的规范有效 `P₀,P₁`，以及对两者均有效的同一规范 `(w,μ)`。在公钥限定的经典理想 `H2` 中，设两地址首位为独立均匀的 `b₀,b₁`；若 `b₀=0` 选 `P₀`，否则选 `P₁`，最终所选公钥的 H2 首位为 0 的概率是 `1/2+(1/2)(1/2)=3/4`。在论文全局 `H̄(w,μ)` 中，两次查询仍是同一位，即使按它选择公钥，该位为 0 的概率仍是 `1/2`。这是**地址模型的区分反例**，不是对真实 SHAKE 或诚实 Setup 的攻击。当前 `paper_backend.setup`（行 115–133）先从种子和见证形成 `P`，不先读取 H1/H2；要把候选解释用于其它归约，仍须检查其公钥确定时序。

## 同一经典理想 XOF 中的矩阵、H1、H2 联合耦合

**模型与前提。** 固定原 Table 4 的一个秩 `d`，考虑具有确定地址数上界的有限经典交互。用一个经典理想 XOF 为每个完整 framed 地址分配独立的无限均匀字节带；对同一地址的多次或不同长度查询返回同一字节带的前缀。`matrix`、`identity`、`message` 是不同的第二字段，长度前缀使有效地址在族内单射、族间不重叠。有限实验保留源码每系数最多 256 次的模 `Q` 拒绝与按全部系数 `count*4096` 字节分配的流预算；比较实验仅对 matrix/H1 采样取消这两项上限，其他代码和随机性共用。若允许对手直接查询理想 XOF 表，此查询只披露同一地址的字节前缀，不消耗派生 API 的流对象预算。令 `M`、`N` 分别是共同路径上最多**首次触及**的不同有效 matrix、H1 地址数，计入派生 API 调用及这些原始预查询；重复地址不增加计数。若实验不开放原始字节访问，才可只数派生 API 地址。`PublicKey.context` 的 SHA-256 与对象层 `SigningKey.identity_digest` 的另域 SHAKE-256 不属于这三个地址族；两比较实验沿共同对象路径以相同代码和输入处理它们，不从本引理推断其随机性。

**条件引理。** 对至多 `M,N` 的任何经典自适应交互，包括承诺和后续地址依赖以前回答的情形，有限版与无限拒绝版的完整 transcript 可耦合，满足

`TV(T_finite,T_infinite) ≤ (M*d²*n+N*d*n)*((2^24−Q)/2^24)^256`。

**证明。** 在某有效地址**首次触及前**，它的整条独立字节带相对共同历史新鲜。预先按无限拒绝解析这条带，定义 `Bad(a)` 为某个系数的前 256 个三字节候选全被拒绝；各系数的起点是此前系数首次接受的停止时刻，未读后缀仍均匀，故单系数坏事件的边缘概率为 `p=((2^24−Q)/2^24)^256`。一个 matrix 地址至多有 `d²n` 个系数，一个 H1 地址至多有 `dn` 个；在地址首次触及的时点作并合，首次坏事件概率至多 `(Md²n+Ndn)p`。之后原始查询即使披露了坏事件，也已计入相应地址；不能在 API 开始时再声称字节对当时历史新鲜。使用同一地址字节带、同一其它随机性和同一自适应策略时，首次坏事件前两实验的 oracle 回答、代码路径及其它状态一致，由耦合不等式得界。代码 `XOFStream.read` 内调用同一 SHAKE 对象的 `digest(k)` 重取前缀；理想字节带以同样方式回放。有限版每系数至多读取 768 字节，在首次 256 次耗尽前总用量也小于其 `count*4096` 字节预算。H2 在 `n=512` 直接读取 64 字节并双射重排为 512 位，故无拒绝项。证毕。

这比[旧预算](../2026-10-18-srgg-oracle-budget/proof.md)的一份矩阵加若干 H1 系数并合多证明了**同一自适应 transcript** 的耦合，且允许 `P` 由 matrix 标签输出构造。诚实 Setup 先完成 `P`，所以在该经典理想模型、私有随机性独立且没有先用 H1/H2 答案选择 `P` 时，条件于形成或接受的 `P`，新 H1/H2 地址仍来自与 matrix 族独立的表；这只支持一份固定 `P` 的抽象地址解释，**不**证明接受 `P` 的分布或发钥 law。若此前已经查询过某 H1/H2 地址，必须回放该地址旧回答，不可把它再说成 fresh。论文全局多公钥游戏和 QROM 不由本引理推出。

**为何必须数原始预查询。** 固定 `d=2` 的已知有效 `P`，先对 2048 个不同的合法身份读取各自 H1 原始地址前 768 字节；若某地址的首个系数有 256 个连续三字节候选全部被拒绝，仅对该身份作一次 H1 API 调用。有限版在该调用中止、无限版继续的概率为 `1−(1−p)^2048>1024p`（由并合下界 `2048p−C(2048,2)p²` 及 `p<2^-1024`），已超过只按一次 API 调用计算的 `dn p=1024p`。把这 2048 个原始地址计入 `N` 后，上面的联合界没有矛盾。该极小概率反例只指出**查询预算定义**的错误，不是可行伪造或安全攻击。

## 有限 H1 耗尽的条件引理

**前提。** 固定一个有效公钥 `P`、原 Table 4 的 `n=512`、`Q=15744063` 和 `d∈{2,3,4}`。经典对手至多触及 `N` 个互异 H1 framed 地址，**原始 XOF 预查询若可用也算在内**；可根据此前回答自适应选择新地址，重复地址使用同一字节带。假设不同 framed 地址有独立无限均匀字节带，其他共享随机性可耦合，且两实验在首次 H1 失败前以相同逻辑运行。此处的 `N` 是互异 H1 地址数，不是仅 API 调用数；实际缓存、故障和服务路径是否满足该实验前提须另核。

**结论。** 单个三字节候选的拒绝概率为 `r=(2^24−Q)/2^24=1033153/16777216`。每个系数至多 256 次尝试，耗尽概率精确为 `p=r^256<2^-1024`。令理想 H1 继续读取直到第一次接受，有限实现则在第 256 次未接受时中止。两实验完整经典 transcript 的总变差距离满足

`TV(T_finite,T_ideal) ≤ Pr[first H1 exhaustion] ≤ N*d*n*p`。

**证明。** `wang_pw.hashing.uniform_values`（行 37–49）在 `Q` 下宽度是 3，接受域 `0,…,Q−1`，每个剩余类恰有一个被接受的三字节代表。候选独立时首次接受的剩余类均匀。对于一个 H1 地址，读取各系数的字节带顺序推进；无限拒绝采样的停止时刻后，未读取字节仍独立，因此 `d*n` 个输出系数独立均匀。给有限与理想实验使用相同字节带及其余随机带；在所有已读取系数未耗尽时，二者读取位置、回答、下一地址选择和 transcript 完全相同。每个地址在**首次触及前**与共同历史独立；其之后的原始读数和 API 调用只回放同一带，不能在已看见该地址的字节后再次声称条件新鲜。按首次触及的至多 `N` 个地址、每址至多 `d*n` 个系数并合，得到 `N*d*n*p`。由耦合不等式得到 TV 界。有限版按 `count*4096` 字节给整条流分配预算，256 次最多消耗每系数 768 字节，不会先触及该预算。证毕。

例如 `N=1` 时三行上界分别为 `1024p`、`1536p`、`2048p`，均严格小于 `2^-1013`、`2^-1013`、`2^-1013`；[既有预算](../2026-10-18-srgg-oracle-budget/proof.md)把**一份矩阵加一份 H1 地址**合计为 `(d²n+dn)p`，与本引理的纯 H1 计数不同。若连矩阵标签的首次理想展开也纳入同一耦合，额外加 `d²n*p`，前提仍是理想独立字节。

不能把结论改写为“条件于整个运行无失败，两份 transcript 完全同分布”。自适应对手可以仅在首个 H1 回答为某固定值时访问第二地址；该分支多承受一次耗尽概率，按全局无失败条件化会重新加权首个回答。证明使用**无条件耦合至首次失败**，不需要这句错误的条件同分布主张。
