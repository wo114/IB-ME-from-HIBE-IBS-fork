# 固定密钥 PW 转换：安全实验与条件归约草案

日期：2026-10-04。状态：**WIP 研究草案，条件命题，尚未完成证明或正式准入。** 本文是本项目提出的补充思路，不是 Pan–Wagner Theorem 2 或 Wang Theorem 5.1 原有的结论。精确工具只检查有限分布与部分控制流程。

原文：[PW §3.2、Figure 1/5、Theorem 2](https://eprint.iacr.org/2021/970)；[Wang Definition 6、Lemma 2.6、Figure 4、Theorem 5.1](https://eprint.iacr.org/2022/1718)。归档文件见 [论文库](../../../papers/index.md)。算法字段及工程边界见 [第三轮接入审查](Wang与PanWagner固定密钥接入审查.md)。

## 1 目标实验 E_cache

只考虑一个主公钥实例，每个外部身份在该实例内有一个密钥生命周期。内部空间为 I、N；J_id、J_msg 是相互独立且与基础 IBS 哈希域分离的经典随机预言机。输入编码必须单射。

```text
Setup:
    (mpk,msk) <- Setup'
    Cache := {}, Corrupt := {}, Signed := {}

GetKey(id):
    if id not in Cache:
        r <- uniform {0,1}^ell
        x := J_id(id,r)
        sk' <- KeyExt'(msk,x)
        Cache[id] := (r,x,sk')
    return Cache[id]

Key(id):
    key := GetKey(id)
    Corrupt.add(id)
    return key

Sig(id,M):
    (r,x,sk') := GetKey(id)
    s <- uniform {0,1}^ell
    y := J_msg(M,s)
    z <- Sign'(sk',y), with fresh signing randomness
    Signed.add((id,M))
    return (r,s,z)

Finish(id*,M*,(r*,s*,z*)):
    reject if id* in Corrupt or (id*,M*) in Signed
    return Verify'(mpk,J_id(id*,r*),J_msg(M*,s*),z*)
```

攻击者可在任意时刻查询四个公开预言机；可以对非目标用户先签名再腐化。最终 r* 不必等于缓存中合法 r。重复原始消息即使出现另一份签名，仍不满足此实验的新鲜性，这是普通不可伪造而非强不可伪造。

该实验未涵盖同一身份多次随机重发独立密钥、多实例共同攻击或一个 epoch 内多份密钥同时使用。实际服务与序列化必须实现其缓存含义后，才能以此实验描述实现。

## 2 条件命题 C1 的必要前提

下面列出候选归约依赖的条件，不能当作本轮已证明的事实。

**A1：基础批量实验可用。** 基础 IBS 满足明确的 UF-naCMA 实验：Setup 前提交基础 Key 身份列表和基础签名对列表，Setup 后拿到密钥/签名并可继续查询哈希，不能追加 Key/Sign 请求。批量签名允许同一个内部身份的多个不同消息。最终目标不得在 Key 列表中，最终内部对不得在**整个**预签名列表中。需要核验 Wang Theorem 5.1 对这种批量联合分布和查询规模的映射，而不只核验一次签名的方程。

**A2：统一的陷门无关采样。** 对每个合格陷门 T、矩阵 F、目标 h，在所有已见历史条件下，以新随机性执行 SamplePre 的分布与 `D_{Lambda_h(F),s_sig}` 的总变差至多 epsilon_sp；理想分布仅依赖 F、h、s_sig，不依赖 T。要对支持的所有密钥、右端和历史给出统一有限界。不同签名的采样随机性必须独立，不能用测试种子或共享随机缓存替代。

**A3：坏密钥与参数事件受控。** TrapGen/DelTrap 的非法或超谱范数事件、采样宽度不足、真实采样尾部/舍入事件各有量化概率。若工程采用超界拒绝发钥/重新发钥，分布变化须计入误差，不能把它视为免费修正。采样形状与 MP12 正负号匹配。

**A4：外层协议是上节实验。** 已有 J_id 点的有意缓存命中不触发新编程；盐长度、两个内部空间、查询上限在 Setup 前固定。标为均匀的量要真正均匀，具体 SHAKE 实现需独立说明偏差/实例化假设。

A2 是从 Wang Lemma 2.6 和 MP12 采样性质出发的待定量条件。它不由单次功能成功或直方图吻合证明；A1 也不能凭论文 Remark 2 一句话省掉。

## 3 固定隐藏陷门的联合分布桥接

对最终未腐化的用户，设其同一 T 被用于 t 次签名。条件于合格密钥及每一步完整历史，用 A2 将第 j 个实际输出替换为陷门无关理想陪集高斯，逐次混合，总变差至多 `t*epsilon_sp`。

基础批量挑战者对同一个内部身份的 t 份签名，可能沿用同一隐藏陷门，或重新合法生成隐藏陷门。只要每个条件化输出仍满足 A2，且每次用新采样随机性，也可逐次替换到同一理想转录，代价至多 `t*epsilon_sp`。因此两份联合转录的桥接代价可保守计为 `2*t*epsilon_sp`，再加各侧坏密钥事件。

这不是由“两个单次边缘分布接近”直接推出积累界；论证依赖**条件化统一界和新随机性**。对可能后来腐化的用户，模拟器必须使用实际预先获得的同一份基础密钥签名，并在腐化时交出该密钥；不能把这些签名替换为与已泄露密钥可能不一致的任意理想输出。

## 4 预承诺槽位与成功事件划分

攻击者最多提出 Q_C 次 Key、Q_S 次 Sig 查询。令 `K = max(1,Q_C+Q_S)`，足够容纳首次通过 Key/Sig 进入缓存的外部身份数。哈希查询不自动建立用户缓存。重复查询同一用户不消耗新槽位。

在基础 Setup 前均匀独立取 `x_1,...,x_K ∈ I`。首次缓存某个外部身份时按出现顺序给它槽位 i，新取 r 并在**未定义点**编程 `J_id(id,r)=x_i`。若点已定义则中止；随后同身份的 Key/Sig 复用该点，绝不重新编程。

槽位值之间及其他独立哈希输出的偶发碰撞另行排除。独立预留值赋给首次使用的、带新盐的输入，不应改变理想 J_id 的分布；需要在正式证明里用延迟决策/耦合处理其与内部预言机转录的关系。

将成功事件分为互斥 F0、F1：

- F0：最终目标外部身份从未被 Sig 查询。因为目标不可腐化，也从未被 Key 查询，故没有已分配缓存槽位。
- F1：最终目标至少被 Sig 查询一次，在缓存中有唯一槽位 i*，但从未被 Key 查询。

两种情况都可能在最终验证之前已查询 `J_id(id*,r*)`。模拟器必须尊重此前记录，不可在看到伪造后任意改写那个点。

## 5 B0：目标从未签名

Setup 前只提交基础 Key 列表 `{x_1,...,x_K}`，无预签名。收到基础公钥及各槽位密钥后，用这些密钥回答在线 Key/Sig，Sig 每次独立取 s 并正常查询 J_msg、调用基础 Sign。对同一个外部身份始终保持既有 r 和基础密钥。

最终输出基础伪造 `(x*,y*,z*)`，其中 `x*=J_id(id*,r*)`、`y*=J_msg(M*,s*)`。在 F0 下目标没有缓存，没有有意编程到槽位的点。若 x* 与任一预请求 Key 的 x_i 重合，归约新鲜性失败，须计入碰撞事件；否则基础身份未腐化，无预签名对，签名有效即为有效基础伪造。

B0 可以在 F1 上失败，不影响它只提取 F0 的概率质量。预请求了但未实际分配的槽位也在基础腐化集合内，不能忽略。

## 6 B1：猜测被签过的目标槽位

Setup 前均匀取 `g ∈ {1,...,K}`。请求所有 `x_i, i!=g` 的基础密钥；独立均匀取 `y_1,...,y_QS ∈ N`，预请求所有 `(x_g,y_j)` 的签名，不请求 x_g 的密钥。

在线行为：

1. 首次出现一个外部身份时分配下一个槽位，按上节取 r、编程 J_id；后续保留。
2. Key 查询非 g 槽位时返回已有基础密钥；查询 g 时中止。
3. Sig 查询非 g 槽位时使用其已有基础密钥正常签名；这也允许之后返回同一密钥。
4. Sig 查询 g 时取新的均匀 s；若 `J_msg(M,s)` 已定义则中止；否则将它编程为下一个未用 y_j，返回对应预签名和同一个 r。Q_S 槽位覆盖所有可能的目标签名次数；无须为所有身份做笛卡尔预签名表。
5. 最后输出 `(J_id(id*,r*),J_msg(M*,s*),z*)`，检查基础 Key 和全部预签名集合的新鲜性。

当 g=i* 时，最终目标不会被腐化，其多次签名保持 x_g；其他用户的后续腐化都能回答。若 r* 等于目标合法 r，则 x*=x_g，没有预请求其基础密钥。若 r* 不同，新的/已查询的 J_id 点应是槽位集合外的独立值，排除碰撞后同样不在基础 Key 集合中。不要限制攻击者只使用合法 r。

原始新鲜消息条件确保 `(M*,s*)` 不等于任何**目标**已签输入。它可能等于其他用户的消息哈希输入，必须保留 J_msg 全局表。排除其他独立输出与整个 y 预留池的碰撞后，y* 不会等于任一预签名 y_j；包括未用的 y_j。若错误地只检查在线发出去的目标签名，基础 UF-naCMA 新鲜性并不成立。

猜测条件下的转录应通过第 3 节的联合桥接与真实实验相近；猜测正确的概率因子是 `1/K`。这一步的延迟槽位分配、隐藏预留值与随机预言机耦合，以及自适应目标选择，都需要完整形式化审查。符号检查不能代替这一步。

## 7 保守误差预算与归约损失

以下是本草案的保守经典 ROM 上界提案，**不是 PW Theorem 2 中原有的常数**。Q_1、Q_2 分别为外层身份/消息预言机查询次数上界，包含签名、发钥引出的查询与最终验证。以下碰撞只计不同独立均匀抽样值之间的意外重合，不把同一输入缓存复用或主动赋给预留槽位算作碰撞。

新盐在已有点上编程的事件，可用

$$
\delta_{prog} \leq \frac{K Q_1+Q_S Q_2}{2^\ell}
$$

保守联合界控制。只对首次建立身份缓存的 r 和猜测目标的每次 s 要求点新鲜；其他用户正常使用已知密钥时可读取已存在的 J_msg 点。

令 `N_1=K+Q_1+1`、`N_2=Q_S+Q_2+1`，一个刻意宽松的全局输出碰撞预算为

$$
\delta_{coll} \leq
\frac{\binom{N_1}{2}}{|I|}+\frac{\binom{N_2}{2}}{|N|}.
$$

这里额外计入未用身份、未用预签名消息池及最终哈希输出。即便攻击者根据以往输出选择最终盐，也要按整个查询预算控制，不能仅写成一个固定最终点的碰撞概率。需要正式核验不同值的独立均匀性及剩余条件；在预算过小时该联合界可能超过 1，此时是无信息的上界。

令 Delta_0、Delta_1 分别收集 B0、B1 的外层编程/碰撞、联合分布桥接和坏密钥误差。可保守把 B1 的桥接部分写为 `2*Q_S*epsilon_sp+p_bad`。若这些模拟条件成立，则候选不等式为

$$
\epsilon_{cache} \leq
\epsilon_{na}(B_0)+K\epsilon_{na}(B_1)+\Delta_0+K\Delta_1.
$$

若进一步完成 Wang 基础证明映射并取得有限误差 Delta_na,0 和 Delta_na,1，可分别将两项替换为相应 SIS 归约优势及误差：

$$
\epsilon_{cache}\leq
\operatorname{Adv}_{SIS}(C_0)+K\operatorname{Adv}_{SIS}(C_1)
+\Delta_{na,0}+K\Delta_{na,1}+\Delta_0+K\Delta_1.
$$

把两个 SIS 优势统一以一个上界控制，外层因子为 K+1。所有统计项也须按这里的因子预算，不能只给一个“可忽略”总称后直接宣称具体安全位数。

运行量也改变：B0 预请求 K 份基础密钥，B1 预请求 K-1 份密钥和 Q_S 份签名；在线非目标签名还需实际执行 SamplePre。基本证明里的统计误差和 RO 查询量须代入这些规模，不能仍只使用原攻击者的 Q_C。本草案没有证明紧归约，不能沿用原文的 `T(B)≈T(A)` 而不计预处理和在线签名成本。

## 8 原文证明与本草案的边界

Wang Theorem 5.1 的 SIS 提取使用证明中隐藏的 `Rhat` 与未公开原像 z'，形成 `e=[I|Rhat]*(z*-z')`。Rhat 是证明模拟的秘密辅助量，不是现实公开哈希陷门。本轮不修改这一基本构造，也不把其零解概率、条件熵或谱范数常数当作已经重新证明。

Lemma 4.2 的认证提取可沿用相同逻辑结构：归约自持 HIBE 主秘密，用缓存版 IBS Key/Sig 回答相应加密密钥和密文查询，解出有效新签名。要获得缓存版整体认证结论，仍需明确 IB-ME 服务的相同发钥缓存规则、E_cache 安全及原组合的所有前提。匿名 HIBE 的隐私证明与字节级完整性包装不由本草案替代。

经典随机预言机可编程不直接给出量子随机预言机证明；这里没有声明 QROM 或标准模型安全。底层 SIS 研究价值与这些模型声明应分开。

1. 把缓存实验、基础批量实验和真实服务中的发钥/重新发钥含义最终冻结；独立审查 A1 与两个成功事件的完整耦合。

3. 审查编程/碰撞预算覆盖提前 RO 查询、同消息盐跨用户复用、另一 r 的最终伪造、未用预留值和自适应目标选择。
4. 写出不含 O/omega 符号的范数与 SIS 误差，再考虑正式参数估计；一维/gadget 采样数学参考实验可先进行，保持 `security_claim: none`。
