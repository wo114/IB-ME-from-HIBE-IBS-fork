# Foo–Li L4：随机性契约与条件式签名失败界

日期：2026-10-06。只处理 Foo–Li 的原始签名向量阶段，不改算法、参数、生产后端或旧规范。
先读 [契约与证明边界](契约与证明边界.md)；机器核验结果以本包 `verification/run-*/verification.json` 为准。

## 1. 证明目标与主入口

在有效主陷门关系、固定状态的 C2 对偶质量条件，以及原始 C4 分布契约下，证明

\[
\Pr[\text{采样中止、模方程错误或}\ \|x\|_2^2>Dt^2]
\le \min\left\{1,\varepsilon_{\rm SP}
+2^{-D}\frac{1+\varepsilon_F}{1-\varepsilon_F}\right\},\qquad
\varepsilon_F=2\varepsilon_0+\varepsilon_0^2.
\]

主入口：[L4.lean](FooLiL4/L4.lean) 中 `l4_from_master_relation`。
该入口由主关系推出满秩，由 L2 推出扩展矩阵的对偶质量界，
从真实无限陪集高斯构造理想概率律，再导出尾界并作一次 TV 转移。
没有把所需理想尾界、理想不中止或主矩阵满秩作为额外未经推导的最终假设。

| 前提 | 数学含义 | 未完成的实际证据 |
|---|---|---|
| 有效主关系 | `A[R0;I]=G`，标准二进制 gadget 有单位列 | 实际 Setup 的关系、质量与成功概率 |
| C2 点态质量 | `Θ_A(s)≤ε0`，`0<ε0≤1/4` | 正式参数下的统一初始化好事件证书 |
| 宽度 | `s>0`、`t≥s`，`m=r+n(k+1)`、`w=n(k+1)`、`D=m+w` | 正式采样宽度、资源及安全参数选择 |
| C4 | 对包括中止的原始实际律 μ，与理想律 ν 的每个事件概率差≤ε_SP | 每个可达合格用户陷门及每个 u 的实际统一证书 |
| 概率/语义 | μ 是概率测度，整数向量 Option 空间单点可测；模方程和平方范数按定义检查 | 真实随机源、持久种子、异常适配、完整签验与序列化 |

这里 Lean 的 `k+1` 是账本 gadget 的完整块长，`r` 是账本的 mbar；不能把两个 k 直接设成同一个数。
主入口假设 q>0，比账本质数模数范围更一般；这不放宽实际密码参数准入条件。
`u` 是任意固定目标，不需要先证明其均匀。用户质量门槛仍负责使实际采样器能够兑现 C4，
不是因为 L4 不直接使用 Q1 就可以取消该检查。

## 2. 本轮新增的连接

1. `Contracts.lean`：定义原始输出、接受谓词和失败事件；证明失败恰为接受的否定。
   定义有限均匀字节带和确定性程序推前概率律，并证明完整事件概率对应带的原像集合。
2. `IdealSignature.lean`：构造无限陪集高斯理想律；证明中止及错误方程的理想概率为零；
   将严格范数失败包含于已有非严格尾事件，连接真实对偶质量与陪集质量比较。
   `mod_append_lifts` 检查整数 lift 再约简后的矩阵确实是 `[A|B]`。
3. `L4.lean`：提供四层入口：固定 F 的平滑/C4、C2/L2 扩展、有限带程序、有效主陷门。
4. `Controls.lean` 与 `Checks/`：精确边界检查与应被拒绝的错误命题。

均匀有限带模型是规范级数学对象。`l4_for_uniform_tape_program` 仍要求针对给定程序证明 C4，
**不意味着 Python 程序、CSPRNG、SHAKE 或种子持久化已获机器认证**。
