# L4 随机性、失败事件与实现接入契约 v1

日期：2026-10-06。基线：仓库 `e150ee40f8153ae6e7f970c9d1a1b316a68254f7`。
本文件在编写 L4 前固定本轮数学边界，不修改生产接口、算法、采样器或参数。

## 1. 范围与量词

沿用上一级《FooLi-条件式正确性定理与参数账本》C1—C5 和 L4。
固定合法公共配置、一个合格的用户状态和任意目标 syndrome `u`。
签名向量空间为 `Fin D → ℤ`，原始输出空间为 `Option (Fin D → ℤ)`：
`some x` 是未按范数/非零条件过滤的输出，`none` 是采样中止。

实际原始概率律记为 μ；理想律 ν 是完整、无限、零中心权重的陪集高斯
`D_{Λ_q^u(F),t}` 经 `x ↦ some x` 得到的概率律。理想律不包含中止质量。
它不是有限枚举分布，也不是先删掉大向量后归一化的分布。

统一 C4 要求：对每个可达合格固定陷门、每个 u，μ 与 ν 的事件概率差
绝对值至多 `ε_SP`。不是仅对某份手选密钥成立，也不是仅对所有用户平均成立。
L4 的定理参数保留此条件；本轮不证明 Python 采样器已实现 μ 或兑现 C4。

## 2. 随机性契约

| 编号 | 数学/实现要求 | 本轮处理 |
|---|---|---|
| R01 | 公共配置确定有限带长 L；带取自 `{0,…,255}^L` 的均匀分布 | 在 Lean 定义均匀有限字节带及确定性程序的推前分布；不声称它等于 Python |
| R02 | 原始程序对每条合法长度带有明确 `some x` 或 `none` 结果；读取不越界、不换带、不补系统随机数 | 数学程序是全函数；实际终止、异常和读取语义仍须另证 |
| R03 | 对固定合格状态，签名带满足 C4 所需的条件均匀性；不能用其自身输出筛选过的带分布 | 作为使用 C4 的实际接入义务；不把独立性“测试通过”当作证明 |
| R04 | 五个预言机域分别为选位、委派带、身份矩阵、消息 syndrome、签名带 | 数学模型按账本保留；本轮不新增真实哈希接线 |
| R05 | 不同域/地址的首次输出独立；同一地址重复调用返回同值 | 经典 ROM 假设；不是实际 SHAKE 已经具有信息论独立性的结论 |
| R06 | 主种子 k1、k2 与用户种子 k_id 按方案独立产生；同一公钥世代/身份持久保存同一用户状态 | 后续需种子保存加载、上下文与配置绑定、重复调用测试；本轮不生成秘密种子 |
| R07 | 身份/消息采用无歧义、带域分隔的编码，签验与重载解释一致 | 沿用 C1/C5；具体后端格式需版本化，不能因本文改变生产接口 |
| R08 | 系统 CSPRNG/真实 SHAKE 与理想带模型的替换说明独立提供 | 未完成；计算不可区分不自动等于信息论 TV 界 |

五域对应账本：`b=𝓗1(k1,id)`、`ψ=𝓗2(k2,id)`、`B=H1(id,b)`、
`u=H2(id,M)`、`φ=𝓗3(k_id,id,M)`。实现还须绑定公钥上下文、密钥世代及配置，
使不同实例不意外复用地址；具体编码应经接口确认，不在本轮臆定。

重复同一身份/消息不是新的独立试验；固定带造成的中止也必须原样重现。
本轮 L4 固定状态和 u；不证明自适应选择消息、已泄露随机带后的转录界，
不证明 ROM 替换、QROM 或安全游戏结论。

## 3. 失败契约

数学验签条件是 `F*x=u (mod q)` 且 `Σ x_i² ≤ D*t²`。
输入维度、签名中的位 b、身份/消息与上下文一致性由 C1/C5 承担；
L4 只分析与之对应的原像向量阶段，不假装覆盖全部字节解析。

| 情况 | L4 表示/处理 | 是否另加采样中止概率 |
|---|---|---|
| `SamplingAbort` | `none`，计为失败 | 否，已经包含在 C4 的完整原始律中 |
| 输出模方程错误 | `some x` 的失败事件；理想律该事件概率为零 | 否，统一通过 C4 转移一次 |
| 范数严格超过门槛 | `some x` 的失败事件 | 理想尾概率加 C4 误差 |
| 范数恰好等于门槛 | 接受 | 不把 `≤` 改成 `<` |
| 零向量 | 不额外拒绝；仍须满足模方程及范数 | 旧后端拒零规则另行决定 |
| 配置、维度、带长错误/不准入 | 公共前置检查错误 | 不能自动声称 C4 覆盖 |
| 合法输入下未预计的软件异常 | 实现缺陷或新增待分析失败 | 不能吞掉、删样本后继续报成功 |

数学坏事件为 `none` 或模方程错误或范数超限。整个事件只作一次 TV 转移。
成功条件分布不能冒充原始 μ；不得先重试到成功再套用本定理。

## 4. 平滑与参数前提

设主矩阵为 A、扩展块为 B、`F=[A|B]`，宽度为 m、w，`D=m+w`。
保留 `s>0`、`t≥s`、`w≤m`、`0<ε0≤1/4`，以及真实对偶质量界
`Θ_A(s)≤ε0`。满秩可由有效主陷门关系及二进制 gadget 导出。
L2 给出 `Θ_F(t)≤εF=2ε0+ε0²<1`；此处不是 MP12 内部 epsilon。

L4 目标：对每个固定合格状态及 u，

\[
\Pr_\mu[\bot\ \text{或}\ Fx\ne u\ \text{或}\ \|x\|_2^2>Dt^2]
\le \min\{1,\varepsilon_{\rm SP}+2^{-D}(1+\varepsilon_F)/(1-\varepsilon_F)\}.
\]

证明顺序：构造理想律 → 证明模方程/不中止支撑 → L2 平滑转移 → 陪集质量与尾界
→ 一次 C4 事件转移 → 概率截断到 1。不把所需尾界直接当作最终入口的假设。
