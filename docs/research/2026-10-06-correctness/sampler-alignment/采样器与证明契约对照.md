## 1. 先看结论

**可以继续做条件式 L4，但目前不能把实际 Foo–Li 实例的 C2—C5 标成全部满足。**

现有参考采样器已经有真实扰动、gadget 原像采样、包含中止的有限误差计算、公共质量类与固定随机带接口，不是仅有模方程的占位实现。逐项对照后，目标分布、平方宽度、委派负号与原始输出位置可以对应到现有证明。

仍需补齐的是：正式参数下的初始化好事件预算；实际随机源、持久种子及调用流程与概率模型的对应；原始中止到协议失败的映射；真实签验和序列化接口。现有有限误差推导与数值库依赖也没有被本次检查变成 Lean 证明。

因此，本报告的结论是“**接口已对齐到可以明确写出剩余证明义务**”，不是“实际采样分布已经完成机器认证”，也不是“安全参数已确定”。本次没有修改生产代码、采样算法、参数或 L1—L3 源码，没有开始 L4 实现。

## 2. 必须固定的数学对象

沿用[条件式正确性账本](../FooLi-条件式正确性定理与参数账本.md)的符号：

\[
k=\lceil\log_2q\rceil,\quad w=nk,\quad m=\bar m+w,\quad D=m+w.
\]

### 2.1 主委派与用户签名不是同一次采样

| 对象 | 主委派阶段 | 用户签名阶段 |
|---|---|---|
| 输入基块 | \(\bar A\) | \(A\) |
| 传入 MP12 的陷门 | \(R_0\) | \(T=-R_{\rm Foo}\) |
| MP12 公共矩阵，tag 固定为单位矩阵 | \(A=[\bar A\mid G-\bar AR_0]\) | \(F=[A\mid G-AT]=[A\mid B]\) |
| 原像输出维度 | \(m\) | \(D\) |
| 理想目标 | 每列 \(D_{\Lambda_q^{B_j-G_j}(A),s}\)，经下述取负适配 | \(D_{\Lambda_q^u(F),t}\) |
| 平方宽度 | \(s^2=r_0^2\kappa_0\) | \(t^2=r_1^2\kappa_1\) |
| TV 预算 | \(\varepsilon_{\rm Del}\ge\min(1,we_0)\) 可取等号 | \(\varepsilon_{\rm SP}\ge e_1\) 可取等号 |

代码 `delegate_stream` 返回的 `trapdoor` 是 \(T\)，满足 \(AT=G-B\)。`DelegatedTrapdoor.foo_li_R_id` 返回 \(-T\)，满足 \(AR_{\rm Foo}=B-G\)。取负保持长度，并将零中心权重的陪集高斯移到相反 syndrome；失败值仍映射为失败。

随后用户 SampleD 要输入代码中的 `trapdoor=T`，不是再输入 `foo_li_R_id`。相同的字母 R 在三个来源中的含义不同，不能机械复制变量名。现有 q=3 测试专门检测这个负号，避免 q=2 把错误隐藏。

### 2.2 宽度和 TV 的单位

- `r_squared` 是 \(r_j^2\)；`sigma_squared` / `Sigma_scalar` 是 \(\kappa_j\)；`spherical_target_width_squared` 是 \(r_j^2\kappa_j\)。不能再次平方。
- 高斯权重采用 \(\exp(-\pi\|x\|^2/a^2)\)。这里 a 不是旧接口中通常正态分布的标准差；非球形字段 `covariance` 在本参考实现中表示高斯参数平方矩阵，不是概率协方差。
- Lean `TVWithin` 是同一输出空间上对每个可测事件的概率差上界。代码证书比较的是完整概率律、包含中止，不是只比较成功样本；不能再额外乘 2，也不能把中止重复计入。
- Lean L3 的 `k+1` 才是 gadget 块长；接代码时 `k_Lean=k_code-1`，不是直接令两个 k 相等。

### 3.1 一个不能混用的 epsilon

`certificate()["MP12_smoothing_epsilon_upper"]` 是内部 MP12 卷积所需的平滑预算，来源涉及 gadget 格和整数格、\(r_j^2,\gamma_j\)。它不是 C2 的

\[
\Theta_A(s)\le\varepsilon_0,
\]

也不是实际初始化失败预算 \(\delta_{\rm init}\)。即使内部字段很小、`sampler_for_quality` 返回 `admitted`，也不能据此把 C2 标为完成。要么为实际好状态单独提供对偶质量/有效格基证书，要么建立适用的生成分布概率论证；本轮没有补做这项证明。

单份状态的证书只解决该状态是否满足前提；对完整 Setup 流程，还必须另证实际不合格/中止的总概率。不能用一份好状态的证书代替 \(\delta_{\rm init}\)。

### 3.2 公共类证书已有，但不能扩大范围

当前工厂固定取整数 \(Q,\gamma\)，并令

\[
\kappa=(\gamma+2)(Q+1).
\]

第十轮给出了该质量类内的谱夹逼、中心分子/分母与所有有限路径的资源推导。源码把这些公共界用于准入；本次九个小陷门只检查实现一致性，不能用九个例子替代整类论证。

绕开工厂、根据每份实际私钥重新调宽度，或任意增大 \(\kappa\)，不能自动沿用同一公共带长/统一资源证书。当前代码最多 128 维、模数不超过 \(2^{32}\)、公开标量平方宽度介于 1 与 \(10^{12}\)，还须满足比例、精度、中心位数、拒绝次数和带长等所有条件；这些是实现上限，不是密码安全参数标准。

## 4. C3/C4 应怎样接到 Lean

以下是待落实的接口规范，不是本次新增的生产函数或 Lean 定理。

### 4.1 先定义原始调用，不先筛选成功样本

固定合法配置、陷门和 syndrome，将足长均匀随机带输入实际采样程序：

```text
RawC4(phi):
    x = sample_from_tape(u, phi)
    正常返回 -> some(x)
    SamplingAbort -> none
```

短带、长带、非法 tag、非法类型、资源不准入通常是 `ValueError`：它们应在 C1 的公共配置/输入检查中排除或明确记录，不能悄悄删除失败样本，也不能一概宣称已被采样 TV 覆盖。合法输入若仍触发未预计的软件异常，须修复或另作有依据的失败分析。

C3 同理：整个委派任一列中止就映射为 `none`；成功则将返回矩阵 T 取负，得到 `some(-T)`，此时尚未做 \(Q_1\) 过滤。质量拒绝放在 L3 的坏事件中。固定合格用户陷门后再定义 C4，因此 C4 的量词必须覆盖每个这样的固定陷门，不能只给“平均用户”的证书。

### 4.2 误差如何接入

在所需数学条件、统一条件采样核和独立均匀字节假设下，阶段 j 的充分上界为

\[
e_j\ge\min\left\{1,
  \frac{4\varepsilon_{{\rm MP},j}}{(1-\varepsilon_{{\rm MP},j})^2}
  +\mu_{p,j}+\mu_{G,j}\right\}.
\]

代码还对区间上端作向外舍入，因此 `tv_upper_including_abort` 可以略大于未舍入的精确表达式。本次专门检查了“证书上界不小于该表达式”，不是强行要求二者数值相等。

经逐列条件耦合和取负，可取

\[
\varepsilon_{\rm Del}=\min\{1,we_0\},\qquad
\varepsilon_{\rm SP}=e_1.
\]

这里的有限拒绝中止已包含在 \(\mu_{p,j},\mu_{G,j}\) 中，不再另加相同中止项。这个连接仍依赖第八/十轮的分析论证；核对公式和运行测试并没有替代该论证的独立审查或形式化。

### 4.3 L4 可以采用的边界

L4 继续证明：对每个合格固定状态、任意 u，在 C2/L2 给出的真实扩展矩阵平滑条件和 C4 原始分布契约下，

\[
\Pr[\text{中止、模关系错误或}\ \|x\|^2>t^2D]
\le\min\left\{1,\varepsilon_{\rm SP}
  +2^{-D}\frac{1+\varepsilon_F}{1-\varepsilon_F}\right\}.
\]

理想陪集分布中的模关系错误和中止质量为零；再用尾界和一次 TV 转移。\(\varepsilon_F\) 应从 L2 的对应前提导出，不能拿内部 MP12 epsilon 顶替。数学范数使用有符号整数的平方和，与精确 \(t^2D\) 比较。

沿用账本的 \(t\ge s\)、\(w\le m\)、\(0<\varepsilon_0\le1/4\)，可取 \(\varepsilon_F=2\varepsilon_0+\varepsilon_0^2\le9/16<1\)。固定好状态的 L4 不需要先算出 \(\delta_{\rm init}\) 数值；合成整个随机初始化流程的 T1 时才必须补齐该项。

现有 `EventBounds.lean`、`GaussianLaw.lean`、`SmoothingBridge.lean` 可复用，但尚未把 Python 随机带程序的推前概率律证明为 Lean 中的实际测度。本轮不能将 C3/C4 从假设列表中删除。
