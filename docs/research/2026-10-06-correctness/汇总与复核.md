## 3. 关键修订与反查

| 问题 | 修订/处理 | 为什么重要 |
|---|---|---|
| 对偶格索引遗漏零模系数的表述风险 | L2 对全部 $a\in\mathbb Z_q^n$ 求和，再删除完整对偶格的唯一零向量 | 非零整数点属于 $a=0$ 陪集，不能丢弃 |
| 仅算子范数不能推出同阈值 Frobenius 准入 | L3 从逐列尾界直接得到 $\|R\|_F^2\le mws^2$ | 对应代码实际检查的 $Q_1$，不是反向推范数 |
| $\tau_D$ 已被 R7 用作委派带长度 | 本文签名尾概率改为 $\tau_{\rm sig}$ | 避免概率与长度混用 |
| 主矩阵误差与 MP12 平滑误差重名 | 分别用 $\varepsilon_0$、$\varepsilon_{\mathrm{MP},j}$ | 二者平滑的格不同，不能互相替代 |
| 固定带重用被误当成独立重试 | T1 限定诚实首访，T2 按不同身份/消息对计数 | 重复失败会重现，不能把概率乘方 |
| 过滤后成功分布冒充原始高斯 | C3/C4 明确比较未过滤且包含 $\bot$ 的完整输出 | 防止漏算中止、条件化偏差或重复加尾界 |
| 初始化近均匀被当作正确性必要条件 | 主定理用真实联合 InitGood；均匀转接仅为可选式 I | 不把安全负面对照直接解释成代数错误 |
| 拒零/重试差异 | 按 P1 验签定义给条件式证明；列出旧生产规范的差异，不改代码 | 不能把旧后端直接标为 Foo–Li |
| Algorithm 3 页码 | 来源以 MP12 固定 PDF 28 页为 Algorithm 3，27 页为 Theorem 5.5 | 不沿用旧报告中含混的“Algorithm 3，27页” |
| 派发提示中的历史数值转录错误 | 主代理本轮重放确认最大范数平方为 **4,158,936,628**，不是 41,589,366,628 | 采用计算结果，不以多代理重复口述作证据 |
