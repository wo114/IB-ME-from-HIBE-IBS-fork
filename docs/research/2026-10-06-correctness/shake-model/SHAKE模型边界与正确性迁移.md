# Foo–Li：先明确随机模型，再进行初始化与总正确性核验

日期：2026-10-06。基线：`5e4ca8d`，研究实现 `FooLi-online-research-v1`。
范围：固定公开合法配置、epoch、身份 id 和消息 M；id/M 在本次实验随机性之前固定。
本文件不是不可伪造性、QROM 安全性或完整 IB-ME 正确性证明。

## 1. 本阶段的结论

理想随机源下的统计正确性与 SHAKE 实例化必须分开。
不能将“SHAKE 的输入有秘密种子”当作均匀随机带的证明，不能给实例化误差填零。
本阶段明确实验、给出手写概率推导、接入可注入的懒采样模型并测试接口；
Lean 对相应概率迁移公式的检查放在后续 `lean-total` 中。

## 2. 三个实验及其精确边界

- G0：所有 Setup/用户种子读取均为独立均匀字节；五类哈希由一个懒采样块随机预言机提供。
- G1：直接熵源仍理想；哈希换成当前的域分隔 SHAKE-256 分块实现。
- G2：当前研究实现，直接熵源也换成操作系统 CSPRNG。

三个实验运行同一个固定的诚实 `Setup → Extract(id) → SignRaw(id,M) → Verify` 流程。
采样中止、质量拒绝、哈希拒绝采样耗尽以及 Verify 拒绝均记为失败；不筛去失败后再取概率。
输入格式错误、资源前置条件不成立、存储损坏和运行库故障在此实验的前提外，不能默默记成小概率误差。

G0 的预言机键为 `(framed(VERSION,domain,context,fields...), u64(counter))`，
每个新键抽取独立均匀的 65536 字节；旧键原样回放。同一地址的不同长度请求必须前缀一致。
每次独立实验从空表开始，无外部预查询；预言机的新块与直接熵源联合独立。
条件化只涉及调用前已揭示的历史，不包括待使用随机带及其输出。同一实验内重复调用不重置表。
不同输入可以偶然得到相同输出，不要求无碰撞。
context 包含版本、完整规范配置、epoch、完整规范主矩阵 A。
先生成 A，再按包含 A 的新地址请求 RO，不造成对这些新回答的预先条件化。

| 用途 | 字段（另有统一 context/domain） | G0 中的作用 |
|---|---|---|
| select-bit | k1,id | 首字节低位为均匀分支位 |
| delegation-tape | k2,id | 委派固定公开长度随机带；每列固定带区 |
| identity-matrix | id,b | H1，有限拒绝采样到 n×w 个模 q 元素 |
| message-syndrome | id,M | H2，有限拒绝采样到 n 个模 q 元素 |
| signature-tape | k_id,id,M | 签名固定公开长度随机带 |

固定一对 id/M 的诚实实验中，委派带与身份矩阵使用不同键；签名带与既有状态/H2 使用不同键。
可按新键顺序逐次抽样。对每个可达的好状态使用统一 C3/C4 界，然后取平均；
不能声称在“完整 RO 表已经固定”的条件下，表内回答仍然随机。
重复签同一 id/M 回放同一结果，不构成独立重复实验。自适应挑选 id/M、重复至成功、
签名查询攻击游戏与任意并发/恢复调度不在本定理范围内。

## 3. G0 下的条件式失败上界（手写推导）

假设初始化证明给出 δinit；所有好主状态满足 C2；原始委派与签名分布满足 C3/C4，
包括中止且不条件化成功。设 τd(e)=2^(-d)(1+e)/(1-e)，eF=2e0+e0²。
由 L3，委派坏事件界为 εDel+wτm(e0)；由 L2/L4，签名坏事件界为 εSP+τ(m+w)(eF)。
界在相应好状态上统一，因此可积分/加权后与初始化坏事件合成；不要求这些坏事件相互独立。

有限模哈希另有 εhash ≤ (nw+n)2^(-T)，其中 T 为每个模元素最大候选数。
这是对未耗尽前新鲜均匀候选的拒绝概率界：每次候选接受率至少 1/2，单元素耗尽率至多 2^(-T)，
再对 nw+n 个元素取并集界。流的读取位置虽依赖此前接受位置，未读取后缀仍独立均匀；
重复验证/重建请求同一 H1/H2 地址不重新计费。该项与高斯内部的 uniform abort 不是同一个事件。

因此

\[
 P_{G0}[Fail]\le\min\{1,\delta_{init}+\epsilon_{Del}
       +w\tau_m(e_0)+\epsilon_{SP}+\tau_{m+w}(e_F)+\epsilon_{hash}\}.
\]

这里使用的 C3/C4 是具体采样器的待核查合同，不因引入 RO 就自动成立。
初始化 I1 的 MP12 几何引理是否已进入 Lean，必须在后续完成情况里单独报告。

## 4. 迁移到 SHAKE：明确假设，不伪装成标准结论

定义本诚实失败事件的差值

\[
 \Delta_{SHAKE}=|P_{G1}[Fail]-P_{G0}[Fail]|,\qquad
 \Delta_{RNG}=|P_{G2}[Fail]-P_{G1}[Fail]|.
\]

若另有依据给出这两个量的上界 α、β，则三角不等式给出

\[
 P_{G2}[Fail]\le\min\{1,B_{G0}+\alpha+\beta\}.
\]

这是**条件式事件迁移定理**。当前没有 α、β 的经证明具体小上界。
只写差值定义并不能证明它们可忽略；没有该假设时，结论仍停留在 G0。
尤其不能声称公开 SHAKE 与独立随机函数对所有算法计算不可区分：
算法可在本地计算公开 SHAKE，再与待测回答比较，立即区分。
因此这里采用明确的 ROM 实例化建模假设/限定事件差值，而非不成立的通用 PRF 主张。
秘密种子的 PRF 分析即使将来补齐，也不自动覆盖公开 H1/H2。

固定输入下 SHAKE 是确定函数。若唯一随机输入只有 κ 位种子，L 位输出的支持最多 2^κ 个，
对均匀 L 位串的 TV 至少为 max(0,1−2^(κ−L))；这是支持集合计数结论，不依赖破解 SHAKE。
它解释了为什么不能拿“长输出看似随机”替代信息论均匀性。
也不要把这条单种子观察错误推广成整个协议的支持数：整个实验还包含其他熵源。

FIPS 202 §6.2 定义 SHAKE256 为可扩展输出函数；它并未提供本协议的 RO 实例化定理。
来源：[NIST FIPS 202 官方页](https://csrc.nist.gov/pubs/fips/202/final)、
[标准正文](https://nvlpubs.nist.gov/nistpubs/FIPS/NIST.FIPS.202.pdf)。
本文概率界、分块适配和协议模型分析是项目推导，不归因于该标准。

## 5. 本次实现与复核边界

`experiments/research/foo_li_oracle_model.py` 提供 LazyBlockOracle，经已有 `oracle=` 注入点接入。
只有注入源为理想均匀字节时，它才实现上述理想分布；用固定测试源运行只验证确定性接口行为。
模型表属于实验环境。恢复私钥必须继续使用同一张表；真实 SHAKE 不需要存表，但这不是二者分布相同的证明。
本轮模型恢复测试限于同进程、同一 oracle 对象；没有声称跨进程模型恢复已实现。
跨进程版本还须保存所有已分配完整块（包括未读后缀），并保证新地址使用独立新熵。
未改 `src/`、旧后端、五个域常量、签名语义或现有冻结的 L1—L4 文件。

新增测试覆盖回放、前缀一致、跨块拆分、域/字段/上下文分离、允许相同输出、熵源长度错误、
两个固定测试源下实际 Setup/Extract/Sign/Verify 及共享模型表恢复。全部是实现证据，不是密码学假设证明。
