## 1. 实质新增的 I3 定理

令 d 为主陷门条目数，r>0 是 Gaussian 参数而非标准差。若

\[
X_i\stackrel{iid}{\sim}D_{\mathbb Z,r},\qquad Q_0\ge d r^2,
\]

则

\[
\Pr\left[\sum_i X_i^2>Q_0\right]\le 2^{-d}.
\]

`FooLiTotal/MasterTail.lean` 从 Poisson 恒等式与对偶网格质量单调性证明
`Z(2r)≤2^d Z(r)`，再导出尾界；**没有把质量比较或尾界作为额外假设**。
同时证明联合质量等于一维质量乘积，识别产品概率律并导出独立性与边缘分布。
入口为 `idealMasterGaussian_quality_tail`、`iid_integerGaussian_quality_tail`。
覆盖 d=0 与阈值等号，失败事件仍是严格超限。

结论对应 MP12 PDF 第 13 页 Lemma 2.6 零中心分支，证明由代码完成，未登记新公理。
原始来源：仓库 `papers/2011_lattice_trapdoors_micciancio.pdf`。

## 2. 条件式合成及前提

记 τd(e)=2^(-d)(1+e)/(1−e)、eF=2e0+e0²，预算为

\[
P_{G0}[Fail]\le\min\{1,\delta_{init}+\epsilon_{Del}
 +w\tau_m(e_0)+\epsilon_{SP}+\tau_{m+w}(e_F)+\epsilon_{hash}\}.
\]

`Pipeline.lean:t1_from_uniform_stage_contracts` 的 `setup` 是**初始化和公共哈希的联合状态律**，
不是仅指 Python 的 `ResearchSession.setup`。它抽取该状态，坏状态输出失败位；
好状态执行委派；**委派中止、关系不合法或质量不合格立即终止并输出失败**；
只有好委派结果继续签名。最终失败包括签名中止、同余错误和完整整数范数超限。
`stopOnBad` 明确实现吸收失败，不能让一个任意签名核在坏委派后“救回”成功。
委派分布必须是质量过滤前的原始律，按 Foo–Li R=−MP12 T 转换，而非 Extract 的成功条件分布。

`bind_event_bound` 直接对前态及转移概率求和：坏前态最多贡献其质量，好前态使用统一界。
不要求坏事件相互独立，也不丢弃失败初始化，不将重复签名当作独立试验。

以下前提仍须保留：

1. 初始化/公共哈希联合坏事件质量≤δinit+εhash。此接线及有限哈希拒绝界尚未由 Lean 中完整 RO 状态机推出。
2. 对**每个**好主状态成立的 C2；I1 几何部分目前是显式外部 MP12 前提。
3. 每个好主状态的原始 C3 和每个好用户密钥的原始 C4；中止已包括在 TV 中。
4. 满行秩、维度、s>0、t≥s、w≤m、0<e0≤1/4、Q1≥mws²，以及误差非负。
5. 上述概率律与真实代码、随机源、持久状态的对应。

将 H2 提前计入 setup/hash 状态，须使用理想模型中其与委派带的独立性，
证明调整抽样顺序保持联合律；该步骤目前在模型说明中手写论证，不是已完成的 Lean 精化。

I4 已接入本轮真正证明的高斯径向尾界；原始生成 TV 与质量→C2 几何仍为前提。
