## 2. 五域、种子与实际采样调用

实现地址先用 Core 的 uint32 长度前缀逐字段编码：

~~~
context = LP(version) || LP(canonical_config) || LP(epoch) || LP(canonical_A)
address = LP(version) || LP(domain) || LP(context) || LP(field1) || ...
block_i = Core.SHAKE256("IBME:FooLi:stream:v1", LP(address)||LP(u64be(i)), 65536)
~~~

流按块拼接并限定公开总长度；不同 read 分块不改变字节序列。context 含完整公开
配置和矩阵，不只依赖一个短上下文摘要。此为版本化**研究编码候选**，没有改写旧生产规范。
不同地址得到不同测试值只是具体测试证据；一般的独立性来自理想模型假设，不由测试推出。

| 原论文域 | 地址字段（另统一绑定 context） | 实际用途 |
|---|---|---|
| 𝓗1 | k1、id | 取输出字节最低位 b |
| 𝓗2 | k2、id | 固定 w 个列带，输入 delegate_stream |
| H1 | id、b | 有界无偏拒绝采样为 n×w 个模 q 元素 B |
| H2 | id、message | 有界无偏拒绝采样为 n 个 syndrome 元素 |
| 𝓗3 | k_id、id、message | 固定公共长度，输入实际 sample_from_tape |

主生成使用 OnlineGaussianGenTrap.generate_from_tape；默认入口取系统 SecureRandom，
审计和所有固定向量实验显式注入 DeterministicRandom。系统入口不等于系统随机源已获信息论证明。
k1、k2 分别调用随机源取 32 字节；每个首次成功发钥的用户另取 32 字节 k_id。
32 字节是本研究编码选择，不是“256 位算法安全”或正式参数决定。

同一身份再次提取返回已保存状态，不重新取种子。同一 id/message 从相同用户种子导出
相同带及原始结果；签名中止也可重放。同一消息重复运行不算新的独立样本。
故障和质量拒绝的身份也保存状态，重复提取不暗中换带。

MP12 返回 T，满足 A T = G−B；研究状态保存 T，Foo–Li 加号记号为 R_id = −T。
用户实际采样矩阵必须为 [A|B]，加载时重新检查关系、维度、质量和选位。
这是 q=3 下的真实符号检查，不只在“负号等于正号”的 q=2 下运行。

### 2.2 失败语义和额外的哈希失败

| 事件 | 返回/处理 | 计入哪里 |
|---|---|---|
| 主生成 SamplingAbort | setup_sampling_abort，不重试 | 初始化联合有限采样 TV |
| 主质量超限 | setup_quality_rejected，不重试 | 主质量尾界 |
| 主关系/资源不变量意外出错 | 抛出错误，不冒称质量拒绝 | 实现缺陷，不能从样本中删除 |
| H1 的模 q 拒绝中止 | identity_hash_abort，缓存 | 新增公共哈希失败预算 |
| 委派 SamplingAbort | delegation_sampling_abort，缓存 | C3 的 ε_Del 中一次 |
| 用户质量超限 | user_quality_rejected，缓存 | L3 理想尾界加 C3 转移 |
| H2 的模 q 拒绝中止 | public_hash_abort | 新增公共哈希失败预算 |
| 签名 SamplingAbort | signature_sampling_abort，原样重放 | C4 的 ε_SP 中一次 |
| 零向量/大向量原始输出 | sign_raw 原样返回；不重试 | 验签检查方程及 ≤ 范数门槛 |
| 错带长、短随机源、意外 ValueError 等 | 抛出；只捕获 SamplingAbort | 非“已证明小概率采样失败” |

原论文 H1/H2 直接输出模 q 元素；有限字节实现增加了拒绝次数 T_U。
一次事先固定 id/message 的完整诚实流程另加保守预算

\[
\varepsilon_{\rm hash}\le(nw+n)2^{-T_U}.
\]

在均匀字节模型中，成功时模 q 元素精确均匀。H1/H2 的重放不是新地址，
因此不因验签重算而重复计费。同一次 SampleD 的内部拒绝中止已在 C4 中，
不能再把它加到 ε_hash；这两个预算对应不同调用。

## 3. 从主陷门质量直接得到 C2

### 3.1 主张与前提

设 q 为本实现支持的质数，k=ceil(log2 q)，w=nk，m=bar m+w。
G 为标准二进制 gadget，A[R0;I_w]=G，||R0||_F²≤Q0，s>0，
0<ε0≤1/4。还需实际公共资源类合法；本实现 m、m+w≤128 等限制不被此数学论证解除。

**命题 I1。** 如果

\[
s^2\ \ge\ \frac{10(Q_0+1)}{\pi}
              \ln\!\bigl(2m(1+1/\varepsilon_0)\bigr),                 \tag{I1}
\]

则 A 满行秩且 Θ_A(s)≤ε0。

### 3.2 推导

1. G 每个块含首列系数 1，因而映射到 Z_q^n 是满射。
   由 A[R0;I_w]=G 可知 A 也是满射。这里没有加入未经证明的随机满秩概率。
2. MP12 §4.2、Lemma 4.3 给出一般模数 gadget 核格基，其最大 Gram–Schmidt
   长度平方不超过 5。q=2 使用 §4.1 的基，平方为 4，因此同一常数 5 可覆盖。
   n 个块作直和不增加最大 Gram–Schmidt 长度。
3. MP12 Lemma 5.3 将该基提升为 Λ_q^⊥(A) 的基 S_A，适当排序后满足
   ||GS(S_A)||≤(s1(R0)+1)||GS(S_G)||。
   使用 s1(R0)≤||R0||_F≤sqrt(Q0)，得到
   \[
   \|GS(S_A)\|^2\le5(\sqrt{Q_0}+1)^2\le10(Q_0+1).
   \]
   最后一式由 2sqrt(Q0)≤Q0+1 得到，不涉及浮点特征值计算。
4. MP12 Lemma 2.3（引用 GPV08 Theorem 3.1）给出
   \[
   \eta_{\varepsilon_0}(\Lambda_q^\perp(A))
   \le\|GS(S_A)\|\sqrt{\ln(2m(1+1/\varepsilon_0))/\pi}.
   \]
   I1 推出 s≥η_ε0；按定义即 Θ_A(s)≤ε0。证毕。

代码以 192 位 MPFI 有向区间计算 I1 右侧的**上端点**，与精确有理数 s² 比较。
未能确认不等式，只返回“充分条件未认证”；不得断言 C2 本身为假，也不得填 δ_init=0。

这条结论对**每一个质量合格的有效主陷门**成立，不只针对抽到的三个样本。
它不是“MP12 内部 epsilon 小，所以 C2 小”：使用的对象是主矩阵核格基及其对偶质量。
初始化状态检查器另检查本次输出关系、规范矩阵、恒等 tag、实际范数和模 q 秩。

## 4. 实际 GenTrap 的初始化概率

### 4.1 联合分布，不是公钥近均匀

设 d0=bar m·w，v=r_gen²，主陷门理想条目独立取自 D_{Z,sqrt(v)}。
理想 Abar 均匀，与 R0 独立，然后同样计算 A=[Abar|G−Abar R0]。

设在线一维采样证书（包含中止）的 TV 上界为 e_Z，均匀模 q 拒绝最多 T_U 次。
对实际**一次、未按质量筛选、未重试**的主生成，可以用逐坐标耦合和并合界取

\[
e_{\rm gen,joint}
 \le\min\{1,\ n\bar m\,2^{-T_U}+d_0 e_Z\}.                         \tag{I2}
\]

模型为独立均匀输入字节。有限循环最多消费公共带长，在每个合法前缀之后，
尚未读取的均匀后缀仍均匀；顺序可变长度读取不改变理想独立采样的耦合依据。
在线标量截断、权重量化和有限中止已包含在 e_Z，不再另加一次生成中止。

I2 比较的是生成过程的**联合 (Abar,R0,⊥) 分布**，不是 Δ(A,U(Z_q^{n×m}))。
代码专门命名 joint_generation_tv_including_abort_upper，不能把它偷换为账本 §7.1
那条可选“公钥近均匀”路线中的 ε_TG。

### 4.2 理想主质量尾界

令 a=floor(sqrt(Q0/d0))+1。若所有条目绝对值≤a−1，则 ||R0||_F²≤Q0。
对一个理想条目，使用归一化质量 ρ_sqrt(v)(Z)≥1 及几何级数：

\[
\Pr[|X|\ge a]
 \le 2\sum_{j\ge0}e^{-\pi(a+j)^2/v}
 \le \frac{2e^{-\pi a^2/v}}{1-e^{-\pi(2a+1)/v}}.
\]

第二步使用 (a+j)²≥a²+(2a+1)j。再并合 d0 个坐标，得到

\[
\delta_{\rm coord}
 =\min\!\left\{1,
  \frac{2d_0 e^{-\pi a^2/v}}{1-e^{-\pi(2a+1)/v}}\right\}.          \tag{I3}
\]

如果 Q0≥d0 v，MP12 Lemma 2.6 的**零中心分支**还给出
δ_radial=2^{-d0}；该分支不要求平滑前提。可以取两种上界的较小值 δ_R。
代码显式保留各项，避免以实际样本未超限代替概率界。
指数极小时采用既有保守区间截断，不把下溢当成零概率。

### 4.3 合成

在 I1 及公共资源前提下，有效生成关系由精确算法保证；
理想生成的坏初始化只需计入主质量超限。一次联合 TV 转移得到

\[
\Pr[\neg\mathsf{InitGood}]
 \le\delta_{\rm init}
 :=\min\{1,e_{\rm gen,joint}+\delta_R\}.                          \tag{I4}
\]

当 I1 没有证实时，本实现保留 delta_init_upper=null，而不是套用 I4。
软件故障、损坏状态或非法参数不自动获得 I4 的概率保证。
系统 CSPRNG 与真实 SHAKE 未被证明是这里的均匀概率空间；
因此证书标记 conditional_uniform_byte_certificate。
