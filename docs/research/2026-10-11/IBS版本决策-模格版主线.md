# IBS 版本决策：Luo 模格版主线

日期：2026-10-11

## 决策

项目当前继续推进 **Luo 2024 模格版 IBS**，配置入口为 `luo-module-research`。Luo 矩阵版暂时停止参数扩展，保留为比较材料和后续备选，不作为当前主线开发对象。

## 决策依据

1. 矩阵版论文没有给出完整的有限 `γ1/γ2` 参数规则。
2. 已完成两轮参数筛选：第一轮 10 行、第二轮 6 行，均没有通过完整筛选。
3. 矩阵版在拒绝采样、公开 LWE 对照和 SIS 范数界之间出现结构性张力，继续盲目扩网格没有充分依据。
4. 模格版已有真实算法实现、参数格式、NTT/Hint 和协议研究接线，可以先形成可复核的研究基线。

逐轮证据见[DeepSeek 参数决策证据索引](evidence/README.md)。

## 适用边界

模格版当前是研究主线和可运行基线，不等于已经完成正式安全准入。后续必须继续核对：

- Luo §4 的算法、参数和 Table 1 对应关系；
- MLWE/MSIS 条件和估计口径；
- 固定身份密钥、缓存和重复签名语义；
- 与 CHKP 两层匿名 HIBE 的通用构造接口；
- 完整 IB-ME 的正确性、攻击验收和公平性能测试。

矩阵版仍保留 `security_claim: none`，不删除已有实现和筛选记录。项目统一状态保持：

```text
security_claim: none
backend_admitted: false
parameters_are_formal: false
```

## 下一步

1. 继续完成模格版论文条件—实现—参数对照；
2. 明确当前参数的安全估计和限制，不直接继承论文安全位数；
3. 等 CHKP HIBE 后端交接后，优先接入模格版 IBS 完成首套组合；
4. 在完整组合稳定后，统一测量尺寸、运行时间、内存和攻击验收；
5. 只有当模格版主线出现不可修复阻塞时，再重新评估矩阵版或其他 IBS。
