### 1.1 困难假设怎么统计

- CHKP + Luo 模格应写成“普通 LWE HIBE + MLWE/MSIS IBS”，不能填成“普通 LWE + 纯 SIS”。Luo 矩阵实现可保留研究对照，但不为了凑纯 SIS 而重新启用不合格参数。
- LATTE 是含 NTRU 结构陷门的 Ring-LWE HIBE 工程候选；匿名条件尚需核准。Lai 原文有 PLWE/收件人匿名性相关声明，仍须映射到本项目的具体两层算法和游戏。
- Sageloli 的环实例才是这里明确列出的 Ring-SIS IBS 覆盖候选；SRGG/Luo 模格不能改称 Ring-SIS。
- Falcon 是 NTRU 结构格上的 SIS 签名；BNN 转换后才形成这里的 IBS。它与 Xie 原生 NTRU IBS 分别登记；底层普通签名、转换后的 IBS、完整 IB-ME 三层分别验收。
- 第三套 HIBE 不强制 Module-LWE。C 复用 A/B 的 HIBE 可形成另一种完整组合，但不会增加 HIBE 算法数。改参数、压缩签名、换采样代码不增加算法数。
- 如果 11 天内 Ring-SIS 固定服务或参数未过门，最终表应明确“Ring-SIS 完整实例未完成”，不能用候选卡、mock 或其他困难假设补位。

6. 公共接口接入与固定身份状态完成后，先通过教学 ABB10+Hybrid 的研究组合；A/B 交付真实 HIBE 后只更换配置，协议代码不另写。

可以将 BNN 通用转换做成一份共享代码，使以后接 ML-DSA 时只换普通签名适配器；本轮最小硬交付是 Falcon 的完整 IBS。共享转换不允许两种实例默认共用机构秘密密钥，也不计作原创转换。

### 5.2 Xie 原生 NTRU IBS 的明确边界

Xie 路线单独占一个算法条目。本轮并行交四算法/参数映射、已有原文模数/可逆性差异的定位、上游 DLP 代码可复用部分；其源码/采样/有限参数未闭合前，不取代 C 的主线。

只有在 BNN-Falcon 主交付已通，且 Xie 的具体参数与算法输入域已澄清时，再认领小型真实原像/签名实验。不得把 Falcon 改名成 Xie IBS，不得把 DLP IBE 包一层接口当作原生 IBS。若 BNN 前提不适配而 Xie 仍未闭合，先如实交阻塞，C 可复用已交的其它 IBS 做协议对照，但不能把它计为自己的新增 IBS。

## 6. 共同接口：每个人都按这个交

完整签名、矩阵/环格式、采样器和参数由原语自己维护。共享协议只看公开接口、不透明对象和装配描述。

| 项目 | 必须满足的契约 |
|---|---|
| HIBE | `setup/extract/derive/encrypt/decrypt/load_ciphertext` 六方法；身份顺序固定 `(parent_id, child_id)=(rcv, phi)`；两个独立 Extract 不能代替委派 |
| IBS | `setup/key_extract/sign/verify/load_signature` 五方法；`sign(sk,message)` 使用密钥已绑定身份；按实际算法处理固定身份缓存/中止 |
| 参数 | HIBE/IBS 各自显式参数类与完整数值；不强制相同 n/q/环/安全假设；论文参数与运行 cap 分列；禁止只存参数名 |
| 对象 | 公钥、主密钥、发钥与密文严格 `to_bytes/from_bytes`；签名由 `load_signature(pk,data)` 载入；核维度/范围/版本/上下文/规范重编码 |
| 身份 | 原始字节非空；CLI 统一 UTF-8；上限是最大长度。Hybrid 原始身份 64 B 时内层两层各 86 B，不能把 86 B 误当两层合计 |
| 容量 | direct 容纳完整签名和消息组帧；Hybrid 内层容纳 32 B seed，外层容纳完整载荷；签名输入还含接收身份与 BYTEAUTH envelope。先算最坏界再实测 |
| 绑定 | Hybrid 必须真实实现公开 HIBE key-binding validator，只接受字面 `True`；参数/版本/公钥绑定不能靠文件名或仅类型检查代替 |
| 状态 | 固定身份钥/叶原像的生成、缓存、保存/恢复、失败和重试语义明确；发钥或解密产生状态变化时先持久化再发布结果；本地单写者不等于防回滚或分布式事务 |
| 随机与错误 | 测试确定流与生产 CSPRNG 分离；需要 Gaussian 的算法说明宽度/误差/实际采样；熵故障/资源中止不返回伪有效对象、不用 mock 兜底 |
| 声明 | 未正式准入保持 `security_claim=none`、`backend_admitted=false`、`parameters_are_formal=false`；同时明确真实研究运行是否已完成 |

新后端交 `BackendSpec` 所需元数据与回调提案：稳定 ID/version、完整参数解析/预设、对象 decoders 与检查器、factory、两层/绑定/状态能力；IBS 交 signature 最大 byte 尺寸及 `master_public_key(master)` 公共适配回调，HIBE 交密文最大 byte 尺寸及胶囊预算。`object_parameter_binding` 如实描述原语对象的选参绑定范围，新后端应保存完整公开参数快照；旧 wire 缺失字段不能靠解析成功追溯。现装配层有明确公共容量字段约定；需要新的参数字段映射时，由 Codex 扩展一个公共适配点，不强制把新算法塞入旧教学 `Params`。

当前目录 `abb-rom/chkp-rom` 是文献候选 ID；运行注册表中教学 HIBE 的 CLI ID 为 `abb10`，CHKP 研究后端为 `chkp`，须在 Sage 环境运行。新后端只有单体/配置检查通过后才登记为可用，不能把目录条目出现当作可运行；登记可用也不授予安全等级。
